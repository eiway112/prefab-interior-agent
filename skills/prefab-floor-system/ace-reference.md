## 二、楼板适用边界表

| 构造类型 | 是否适用 ACE IC-08 | 说明 |
|---------|-------------------|------|
| 浮筑砂浆面层 | 是 | M5 模型典型适用场景 |
| 浮筑板材面层 | 是 | 需将板材等效为面密度 m' |
| 架空地面 | 否 | 支撑脚-空腔系统不适用 M5，需采用 MSM/FE 模型 |
| 干法调平 | 否 | 隔声改善有限，通常不满足 L'nT,w ≤ 65 dB 高要求 |
| 快装地面 | 否 | 依赖垫层与锁扣构造，无通用模型 |
| 带地暖的浮筑地面 | 部分适用 | 地暖层计入 m'，但热工/结构边界需转介 |

> 表中「M5」「MSM/FE」指模型名称，其公式与适用参数范围不在本文件登记：M5 见 `reference.md §三 A2`，MSM 见 ACE 技能自身参考文件。

## 三、ACE 不可处理因素（U-01 ~ U-08）

| 编号 | 不可处理因素 | 处理方式 |
|------|--------------|---------|
| U-01 | 异形/非匀质基层楼板 | 转介专业声学模拟 |
| U-02 | 存在刚性声桥 | 先消除声桥再估算 |
| U-03 | 大面积开洞/管线穿越 | 转介专项设计 |
| U-04 | 缺乏弹性垫 s 参数 | 要求厂家提供检测报告 |
| U-05 | 基层楼板 Ln,w 未知 | 按经验基准取值并声明 |
| U-06 | 多层复合浮筑构造 | 简化等效或转介 FE 分析 |
| U-07 | 面层为特殊弹性材料 | 需校准 M5 常数 C |
| U-08 | 现场混响/侧向传声显著 | 现场检测替代估算 |

> 命中 U-01~U-08 任一项时，不得以本文件二、两表的「适用」结论继续估算；须在输出中列出命中的编号与处理方式，并声明该构造的数值未经 ACE 计算。
