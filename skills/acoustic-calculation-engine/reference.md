## 一、物理模型库

### M1 质量定律模型（Mass Law）

**公式**：

```
R(f) ≈ 20·log₁₀(m·f) - 47.2  [dB]
```

其中 m 为面密度（kg/㎡），f 为频率（Hz）。

**简化估算**（单值评价）：

```
Rw ≈ 20·log₁₀(m) + K
```

K=0 为仓内统一口径（2026-08-07 仲裁确定，见下方声明）。简化式仅用于单板概念性相对比较与预估，不得作为确定性 Rw 输出；确定性取值以 CMA/CNAS 检测报告为准。

> **口径冲突仲裁结论（2026-08-07，CG-20260807-011）**：M1 简化式 K 值与隔墙技能（prefab-partition-wall-solution）reference.md §3.B.2 原取值 K=−7 的冲突已仲裁终结。核查结论：① 隔墙技能原标注"来源 GB/T 50121-2005"经 S1 级原文核验（建设部公告第356号发布版）为引用错误——该标准仅含 Rw/C/Ctr 单值评价方法（基准曲线表 3.1.2、数值法 §3.2.1），不含任何隔声量预测公式；② 按 GB/T 50121-2005 §3.2.1 数值法对纯质量定律频谱（场入射 −47.5 dB 常数）求 Xw，理想化截距约为 +10.5 dB（可复现推导）；③ 隔墙技能 MSM 估算流程（基准+增益表）与其仓内行业测试数据（§7-9 共 5 组构造）仅在截距 ≥0 时自洽，K=−7 导致系统性偏低 7 dB。据此统一采用 **K=0（仓内经验校准口径，S2 级统计校准，非标准公式）**，即 ACE 默认值维持不变；已知局限：单叶密实板材（如石膏板）绝对值可能仍偏低 5-7 dB（理想化截距 +10.5 与多孔材料实测分化所致），已列入精度声明。频率域常数 −47.2（ACE）与 −47.5（隔墙技能）差 0.3 dB，在精度范围内不构成实质冲突。

**输入参数**：

| 参数 | 符号 | 单位 | 必填 |
|------|------|------|------|
| 面密度 | m | kg/㎡ | 是 |
| 频率 | f | Hz | 频段分析时必填 |

**适用范围**：
- 单层均质构造（石膏板、硅酸钙板、纤维水泥板、ALC 条板等）
- 中频段（约 200-2000 Hz）估算精度最佳
- 面密度加倍 → 隔声量约增加 6 dB（质量定律核心预测）

**精度声明**：±3-5 dB（单层均质板中频段）。不含吻合效应修正，不含低频共振和高频阻尼效应。

**不适用**：
- 多层复合构造（须叠加 M3/M4）
- 吻合效应影响区（须结合 M2）
- 极低频（<100 Hz）和极高频（>5000 Hz）

> **轻质构造区（面密度 <30 kg/㎡）特别声明（2026-08-07 溯源更新，CG-20260807-011；阈值表述经 CG-20260807-016 恢复）**：联调 V1 场景（双面 12mm 石膏板龙骨墙，m≈19.2 kg/㎡）M1 基线仅约 26 dB 的根因经溯源确认为**适用域错误**——M1（单层均质质量定律）不适用于双叶构造，双叶墙应按 M3（MSM）模型估算（该构造按 M3 基准+增益法估算约 38-42 dB）。原引用的"实验室 Rw 典型值 45-50 dB"（出自《ACE接口联调验证报告_20260624.md》F1）经交叉核验**与仓内行业测试数据矛盾**——隔墙技能 reference.md §9.2 载"75mm单排龙骨+岩棉+单侧双层石膏板"约 40-45 dB，单面单层构造不可能高于单侧双层，该 45-50 dB 疑似偏高（或混淆双层/双排构造），维持 S3 级"待检测报告验证"状态。本区内**禁止以经验值静默覆盖物理计算结果**：双叶构造必须路由 M3 计算，输出须同时保留物理计算值与经验参考范围，经验范围必须标注数据源等级与验证状态。

### M2 吻合效应模型（Cremer 薄板理论）

**公式**：

```
fc = c² / (2π·h) × √(12(1-σ²)·ρ/E)  [Hz]
```

其中：

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 空气中声速 | c | m/s | 取 343 m/s（20℃标准条件） |
| 板厚 | h | m | 注意单位换算 |
| 板材密度 | ρ | kg/m³ | 体积密度 |
| 弹性模量 | E | Pa | 杨氏模量 |
| 泊松比 | σ | — | 无量纲 |

**修正因子说明**：公式中 `√(12(1-σ²))` 为弯曲刚度修正因子，来源于薄板弯曲波理论（σ=0.25 时 ≈3.354）。它含两部分作用：① 常数项 `√12≈3.464` 反映板厚方向弯曲刚度，是**主导项**——若整体省略该因子（退化为简化版 `√(ρ/E)`），fc 将偏低约 70%（简化式仅为完整式的 29.8%；如 12mm 石膏板 ρ800/E2.5/σ0.25 由 2961 Hz 误算为 883 Hz，比值 3.354）；② 泊松比项 `√(1-σ²)` 是**次级修正**，σ 在 0.2-0.3 内变动仅使因子变化约 2.6%。故简化版 `√(ρ/E)` 不可用于定量计算，ACE 始终使用完整修正公式。

**吻合效应风险判定**：

| fc 与评价频率带的关系 | 风险等级 | 说明 |
|----------------------|---------|------|
| fc > 4000 Hz | 无 | 吻合谷在计权频率范围之外 |
| 2500 Hz < fc ≤ 4000 Hz | 低 | 吻合谷边缘进入计权范围，影响有限 |
| 800 Hz < fc ≤ 2500 Hz | 中 | 吻合谷落在中高频核心计权区 |
| fc ≤ 800 Hz | 高 | 吻合谷落在低频区，对 Rw+Ctr 影响显著 |

**异质复合吻合谷错开判据**：

当两块不同板材复合使用时，吻合谷错开可有效削弱单一吻合谷深度。判定标准：

```
Δfc = |fc₁ - fc₂| ≥ 300 Hz → 有效错开
```

该判据对弹性模量 E 高度敏感且**非单调**。以 12mm 石膏板（ρ800/E2.5/σ0.25，fc≈2961 Hz）+ 10mm 硅酸钙板（ρ1400/σ0.22）为例，按修正公式复算：
- E(硅酸钙) = 8 GPa 时，硅钙板 fc≈2647 Hz，Δfc ≈ 314 Hz（边界有效）
- E(硅酸钙) ≈ 6.3 GPa 时，两板 fc 相交，Δfc → 0（吻合谷叠加，最不利）
- E(硅酸钙) = 5→4 GPa 时，Δfc 回升至 388→783 Hz（重新有效）

即 Δfc 随 E 先减后增、在 E≈6.3 GPa 过零，不能由单一 E 点外推；该组合在声明参数域内无法保证有效错开。当错开无效时，ACE 建议更换板厚或板材类型（如改用 8mm 硅酸钙板或 15mm 石膏板），并按所选产品实测 ρ/E 复核 Δfc。

**输入参数**：

| 参数 | 符号 | 单位 | 必填 |
|------|------|------|------|
| 板厚 | h | mm | 是 |
| 板材密度 | ρ | kg/m³ | 是 |
| 弹性模量 | E | GPa | 是 |
| 泊松比 | σ | — | 是（无数据时用典型值） |

**精度声明**：fc 计算精度约 ±10%（受材料参数离散性影响）。吻合谷深度和宽度取决于板材阻尼系数，ACE 不做定量估算，仅做风险频率定位。

### M3 质量-弹簧-质量模型（MSM）

**公式**：

```
f₀ ≈ 600 / √(d × m_red)  [Hz]
```

其中：

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 空腔深度 | d | cm | 注意单位为厘米 |
| 约化面密度 | m_red | kg/㎡ | m_red = m₁·m₂ / (m₁+m₂) |
| 面板1面密度 | m₁ | kg/㎡ | 一侧面板 |
| 面板2面密度 | m₂ | kg/㎡ | 另一侧面板 |

**MSM 常数说明**：公式中的常数 600 由 `1/(2π) × √(ρ_air × c² × 100)` 导出（空气密度×声速²×单位换算），其隐含假设是空腔内为空气弹簧。该导出式不含面密度项，故常数的精确性**不依赖 m₁ 与 m₂ 是否相近**（ρ_air=1.2 kg/m³、c=343 m/s 时代入得 598 ≈ 600）。m_red 约化质量式对任意正质量比精确成立（见下条「非对称构造适用性」第 1 条）；面密度是否对称影响的是**近对称近似式**（按总质量的 1200 式，见下条第 2 条）的精度，不影响本式。

**非对称构造适用性（三面分清）**：

1. **约化质量恒等式（本件 M3 公式）**：f₀ = 600/√(d×m_red) 源于理想两质量-一弹簧系统非零模态的精确解 ω² = k(1/m₁+1/m₂) = k/m_red，**对任意正质量比精确成立**〔复算：质量比 r=0.1—10 下特征方程非零根与 k/m_red 相对偏差恒为 0，凭据＝CG-20260925-001 复算取证 §一〕。质量比本身不使本公式产生偏差。原「m₁/m₂ 超出 0.5—2 产生 5-13% 偏差」的提示区间因归因在理想模型内不成立、且无可定位实测来源而**撤回**（撤回无据结论，不给替代偏差值）。
2. **近对称近似（另一公式，非本件 M3）**：按总质量的近似式 f₀ ≈ 1200/√(d×(m₁+m₂)) 仅适用于 m₁≈m₂，其频率偏差在 r=2 约 −5.7%、r=3 约 −13%〔复算 §二〕。非对称构造须回到本件 M3 精确式；不得把近似式的误差误归为约化质量式的适用域限制。
3. **真实模型误差（模型外假设）**：M3 与实测 f₀ 的偏差来自理想模型之外的假设，逐项显式列出：声桥（龙骨等刚性连接）、阻尼（填充材料耗能）、边界条件（板尺寸有限与边缘约束）、板弯曲模态（集中参数近似适用于 f₀ 远低于板第一弯曲模态时）、空腔无质量弹簧假设（适用于 f₀ 远低于空腔四分之一波长共振 c/4d 时）。

ACE 在假设说明中标注非对称度（m₁/m₂），供构造形态识别；精度降低的归因按上列第 3 条模型外假设逐项作出，不按质量比本身归因。

**f₀ 与 Rw 增益路径**：

MSM 共振频率 f₀ 决定了双层构造的隔声增益起始点：

| f₀ 与计权频率带的关系 | Rw 增益预估 |
|----------------------|-----------|
| f₀ < 100 Hz | 双层构造在整个计权范围内有效增益 |
| 100 Hz ≤ f₀ < 200 Hz | 增益存在，但低频段部分抵消 |
| f₀ ≥ 200 Hz | 增益显著削弱，低频段可能出现隔声低于单层的情况 |

**经验增益估算**（粗略）：

```
当 f₀ < 200 Hz 时：
  Rw(双层) ≈ Rw(等效单层) + 空腔增益(M4) + 填充增益(M4) + 解耦增益(M4)
当 f₀ ≥ 200 Hz 时：
  增益大幅衰减，须标注"MSM 共振频率过高，空腔增益有限"
```

**输入参数**：

| 参数 | 符号 | 单位 | 必填 |
|------|------|------|------|
| 面板1面密度 | m₁ | kg/㎡ | 是 |
| 面板2面密度 | m₂ | kg/㎡ | 是 |
| 空腔深度 | d | mm | 是（内部转换为 cm） |

**精度声明**：f₀ 计算精度约 ±10%。Rw 增益为区间估算（±3-5 dB），受空腔填充、连接方式等因素影响。

### M4 空腔增益叠加模型

空腔增益是 M3 的后续叠加项，评估双层/多层构造相对于单层等效构造的额外隔声增益。

**空腔深度增益**：

| 空腔深度 | 增益 | 说明 | 来源 |
|---------|------|------|------|
| < 50 mm | 0-2 dB | 空腔过浅，弹簧刚度大，MSM 共振频率高 | 经验归纳 |

**双空腔系统（三质量-两弹簧耦合系统）**：

### M5 撞击声改善模型（撞击声场景专用）

**公式**：

```
f₀ = (1/2π) × √(s / m')  [Hz]
ΔL ≈ 40·log₁₀(f / f₀)  [dB]（f > f₀ 时）
```

> **s 的单位绑定（本节两式标度不同，勿混用）**：上式 f₀ 为 SI 量纲式，s 须以 **N/m³** 代入（产品值常以 MN/m³ 标注，按 `1 MN/m³ = 10⁶ N/m³` 换算）；下方 ΔLw 单值评价式为经验定标式，s 按 **MN/m³ 的数值**直接代入，且其常数 C 与该标度同定（C=10 只在 s 取 MN/m³ 数值时成立）。若把 N/m³ 数值代入 ΔLw 式，`-10·lg(s)` 项会多减 60 dB，结果整体下移 60 dB。参数表所列 s 单位（MN/m³）适用于后者。

其中：

| 参数 | 符号 | 单位 | 说明 |
|------|------|------|------|
| 弹性垫动态刚度 | s | MN/m³ | 产品检测值或典型值；单位绑定见上注（f₀ 式须先换算为 N/m³） |
| 浮筑层有效振动面密度 | m' | kg/㎡ | 弹性垫上方共同运动各构造层的单位面积质量之和；不含结构楼板、不含弹性垫自身，组成与排除见下方「m' 口径」条 |

> **m' 口径（有效振动面密度，不是结构荷载）**：
>
> 1. **组成与排除**：m' ＝ 弹性垫层以上共同运动的各构造层（找平／保护层、砂浆垫层、饰面层等）单位面积质量之和。排除三项——**不含结构楼板自重、不含弹性垫自身质量、不含活荷载与可变堆载**。须逐层列明厚度与密度后相加，不从单层厚度反推整层质量（与楼地面技能方案表「浮筑层面质量 m'」同一口径）。
> 2. **与永久荷载（恒荷载）的关系**：两者取材同源、用途不同——恒荷载是结构承载力口径（计入弹性垫、按 kN/m² 表达），m' 是声学质量-弹簧模型口径（不含弹性垫与楼板、按 kg/㎡ 表达），**不得互代**。误代后果可复算（s=15 MN/m³、50mm 砂浆 85＋10mm 瓷砖 22 kg/㎡ 构造，楼板 288 kg/㎡）：以含楼板的合计恒荷载代入 m' → ΔLw 虚高约 10.2 dB、f₀ 低估约 48%；漏计砂浆垫层只计面层 → ΔLw 低估约 12.4 dB、f₀ 高估约 120%；计入弹性垫自身（8 mm×900 kg/m³≈7.2 kg/㎡）→ ΔLw 偏大约 0.5 dB。前两类偏差已超出本节精度声明区间，判据是「计入即口径错误」，不因偏差方向保守而豁免。〔复算凭据＝CG-20260925-003 取证 `m5e_recalc.py` §一〕
> 3. **模型外假设**：本式将浮筑层视为集中质量。实际面层在高频段以弯曲波运动，参与共同运动的有效质量小于全断面面密度，故 m' 作集中质量使用仅限 f > f₀ 的质量控制区；本件不提供高频有效质量折减的定量式，不得自造修正值。

**单值评价**：

```
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C
```

C 为经验修正常数，典型取值 8-12。ACE 默认 C=10。

> **C 的证据状态**：本件未记录 C 的定标依据（所用构造清单、样本量、实测偏差统计），故 C=10 与典型区间 8-12 同属**待独立验证的经验定标取值**，不得表述为已按多构造校准所得，也不得作为可核验精度证据对外引用；C 值受楼板基层刚度、垫层老化、边缘隔离质量等因素影响，项目实测以检测报告为准。原以 C 的取值解释约 5 dB 量级系统性偏差、并称默认值经多构造校准得到的两句，因无可定位数据且与下条公式灵敏度不符而**撤回**，不给出替代解释值。
>
> **C 的灵敏度（为何 5 dB 量级偏差不应归因于 C）**：C 在 ΔLw 式中是加法项，∂ΔLw/∂C ≡ 1 dB/dB——C 由 10 取到 12 只使 ΔLw 变化 2.00 dB，C 在整个典型区间 [8,12] 内变动的全部影响幅度只有 4.00 dB。因此预测与实测差达 5 dB 量级时，排查方向不在 C 的取值，而须回查 m' 口径（误代恒荷载或漏计构造层，见上方「m' 口径」条）、s 的取值与单位标度、以及基层刚度／垫层老化／边缘隔离等施工条件。〔复算凭据＝CG-20260925-003 取证 `m5e_recalc.py` §二〕

**Ln,w 估算路径**：

```
Ln,w(浮筑) ≈ Ln,w(裸板) - ΔLw
```

裸板 Ln,w 基准值：

| 楼板类型 | 面密度 | Ln,w 基准 | 来源 |
|---------|--------|----------|------|
| 100mm 钢筋混凝土 | ~240 kg/㎡ | 78-82 dB | 检测统计 |
| 120mm 钢筋混凝土 | ~288 kg/㎡ | 76-80 dB | 检测统计 |
| 150mm 钢筋混凝土 | ~360 kg/㎡ | 74-78 dB | 检测统计 |

**输入参数**：

| 参数 | 符号 | 单位 | 必填 |
|------|------|------|------|
| 楼板面密度 | m_slab | kg/㎡ | 是（仅用于查裸板 Ln,w 基准表，不进入 f₀ 与 ΔLw 的质量项） |
| 弹性垫动态刚度 | s | MN/m³ | 否（无数据时用典型值并标注）；单位绑定见本节"s 的单位绑定"注 |
| 浮筑层有效振动面密度 | m' | kg/㎡ | 是（组成与排除见本节「m' 口径」条；与 m_slab 分列，不得合并为恒荷载合计代入） |

**精度声明**：ΔLw 估算精度约 ±3-5 dB。Ln,w 估算精度约 ±4-6 dB，受弹性垫参数离散性和施工质量影响较大。该模型需补充实验数据校准。

### M6 声桥/缝隙修正模型

**声桥修正**：

刚性连接节点（龙骨贯通、管线穿透、构件搭接等）形成声桥，导致隔声量下降：

| 声桥类型 | 隔声量下降 | 说明 | 来源 |
|---------|----------|------|------|
| 龙骨刚性连接 | 3-5 dB | 常规轻钢龙骨隔墙 | 经验归纳 |
| 贯通构件（管线/桥架） | 3-8 dB | 取决于穿透面积和密封处理 | 经验归纳 |
| 节点搭接不连续 | 2-5 dB | 板材接缝处 | 经验归纳 |
| 严重声桥（多处贯通） | 8-15 dB | 极端情况 | 经验归纳 |

**缝隙修正**：

构造缝隙导致声泄漏，按面积比估算隔声量下降：

```
R_composite = -10·log₁₀[(1-p)·10^(-R_wall/10) + p·10^(-R_gap/10)]  [dB]
```

其中：
- p = 缝隙面积 / 总面积（面积比）
- R_wall = 墙体隔声量
- R_gap = 缝隙隔声量（通常取 0-5 dB）

**简化估算**：

| 缝隙面积比 | 隔声量下降 | 说明 | 来源 |
|-----------|----------|------|------|
| 0.01% | 约 0 dB | 密封良好，影响可忽略 | 本式复算 |
| 0.1% | 约 2-4 dB | 轻微泄漏 | 本式复算 |
| 1% | 约 8-12 dB | 显著泄漏，隔声严重削弱 | 本式复算 |
| > 1.5% | > 12 dB | 严重泄漏，构造隔声接近失效 | 本式复算 |

> **本表适用前提（不得当普适值使用）**：上表由上式在 **R_wall ≈ 30 dB、R_gap = 0 dB** 的特例算得（复算：p=0.01%→0.4 dB、p=0.1%→3.0 dB、p=1%→10.4 dB、p≈1.49%→12.0 dB，与上表 0／2-4／8-12 dB／>12 dB 四档逐档吻合，最细档本表记为"约 0 dB"；末档下界 1.5% 为损失达 12 dB 阈值（p≈1.49%）向上取整的保守边界，1%—1.49% 区间损失为 10.4→12 dB，并未越过 12 dB），对应普通轻钢龙骨隔墙量级。同一缝隙面积比造成的损失随 R_wall 升高而**增大**：R_wall=50 dB、R_gap=0 时 p=0.1% 即降约 20 dB。故 R_wall 明显高于 30 dB 的构造（如 Rw+C≥50 dB 的分户墙）不得套用本表，须按上式以实际 R_wall／R_gap 现算，或改用按墙体隔声等级分层的损失表（`prefab-partition-wall-solution/reference.md` §3.B.2「缝隙与孔洞的影响」）。

> **单值代入口径（近似声明）**：上式把 Rw 单值直接代入能量合成，属近似口径——严格路径为逐频带（1/3 倍频程）能量合成后按单值评价量（GB/T 50121）计权，缝隙泄漏的能量占比随频带分布不同会使边界档读数偏移；缝隙主导段（R_composite 趋近 −10·lg(p)）读数偏差有限，墙体主导段偏保守，不得当逐频带合成结果使用。

**ACE 行为规则**：
- 所有构造均须评估声桥和缝隙风险（对应红线 ACE-R-P1-1 和 ACE-R-P1-2）
- 即使输入未指定密封方式，ACE 也须输出密封评估并标注"密封方式未指定，按常规密封评估"
- 声桥风险等级：无 / 低 / 中 / 高

### M7 基准校准模型（Baseline Calibration）

> **历史标签覆盖注（CG-20261022-017，PL-229 暂停期）**：本节 Step 3／Step 5 与算例中的「工程取值」「工程推荐值」「仅作方法演示」是**历史研究口径的标签**，不构成工程许可。对外答复与研究报告一律改称「研究复算值（非工程结论）」；不得以「工程取值／工程推荐值／参考值／区间／误差范围／方法演示／仅研究」等名义把本节输出包装成工程可用值。本节公式、常数与算例数值均不因本注改变。

**模型定位**：当调用方提供已知构造的权威隔声基准数据（标准设计图集或 CMA/CNAS 检测报告）时，ACE 以该数据为锚点，通过面密度比对与参数差异修正，反推同族变体构造的隔声量。M7 不做从零理论计算，而是「锚定 + 差分外推」，用于规避纯模型估算对特定构造族的系统性偏差。

**方法论依据（S1）**：ISO 12354-1:2017 估算框架以构件实验室实测性能数据为输入估算建筑隔声性能——基于权威实测数据估算属方法论主流。基准 Rw 须按 GB/T 45305.2-2025《声学 建筑构件隔声的实验室测量 第2部分：空气声隔声测量》（2026-02-01 实施，全部代替 GB/T 19889.3-2005〔2026-02-01 废止，2026-08-20 经全国标准信息公共服务平台核验〕）测定并按 GB/T 50121-2005 单值评价，或出自出版的标准设计图集；按 GB/T 19889.3-2005 测得的历史基准仍可作为锚点，但须在假设说明中注明测量标准版本。

**适用前提（三条须同时满足）**：

1. **基准来源可信**：标准设计图集（记录图集名称/页码）或 CMA/CNAS 检测报告（记录报告编号）。来源不明、无法溯源或疑似伪造的不予校准。
2. **构造同族**：基准与变体构造的结构形式（单叶 / 双叶+空腔等）与支撑体系类型相同，差异主要为面板层面密度（板型/厚度/层数）、空腔填充等参数。
3. **无机理级变化**：连接方式未改变（如共用龙骨→独立双排龙骨）、叶片数量未增减、密封体系未变。机理级变化使面密度比对失效，须回退 M1-M6 全模型计算。

**计算方法**：

**Step 1 — 面密度计算**：

```
m_base = 基准构造面板层面密度（+ 龙骨/配件分摊面密度，见口径说明）
m_new  = 变体构造面板层面密度（同口径）
r = m_new / m_base   （面密度比）
```

> **口径说明**：面密度比宜按两侧面板层计（龙骨面密度不参与叶片隔声）。含龙骨/配件分摊质量的比值会把 r 推向 1、使 |ΔR| 略减小，工程可用，但须在假设说明中标注口径。**其保守性方向随 r 而反**：r>1（增重）时 |ΔR| 偏小＝低估增益＝偏保守；r<1（减重）时 |ΔR| 偏小＝低估降幅＝偏乐观（下方校准算例的变体 A 即 r<1 一侧）。

**Step 2 — ΔR 区间确定（S3，物理模型推导）**：

```
单叶构造:            ΔR = 20·lg(r)                    （质量定律）
双叶质量定律界:      ΔR_low  = 20·lg(r)               （质量定律主导/弱耦合叶）
双叶叠加界:          ΔR_high = 40·lg(r)               （理想空腔区、对称双叶、无声桥）
输出区间（恒升序）:  [min(ΔR_low, ΔR_high),  max(ΔR_low, ΔR_high)]
```

物理依据：质量-空气-质量共振频率以上的质量控制区，无刚性桥接的解耦双叶构造隔声量近似两叶之和（R ≈ R₁ + R₂）；两侧面密度同步缩放系数 r 时增益上界为 2×20·lg(r) = 40·lg(r)；下限退化为单叶质量定律 20·lg(r)。实际轻质双叶墙存在龙骨声桥，实现值落在两界之间。

> **位名与大小排序不是一回事（端点判据）**：`ΔR_low`／`ΔR_high` 是上式两界的**位名**（与脚本参考实现 `m7_delta_R_bounds` 的返回值序一致：第一＝20·lg(r)、第二＝40·lg(r)），**不表示数值谁大谁小**。r>1（增重）时 40·lg(r) 更大，位名与大小一致；r<1（减重）时 40·lg(r) 更负，`ΔR_high` 反而是区间下限（其物理含义变为"降幅的上界"）。故对外输出的区间端点一律由 min/max 决定、恒为升序 [较小值, 较大值]，不得按位名直接当作 [下限, 上限] 输出。

**Step 3 — 工程取值（S4，行业经验估计，须标注经验规则）**：

```
对称变化（两侧叶同步变化）:  ΔR 取区间中值，同时输出区间——端点一律按数值升序，
                             即 Step 2 的 [min(ΔR_low, ΔR_high), max(ΔR_low, ΔR_high)]，
                             不得按位名写作 [ΔR_low, ΔR_high]（r<1 时该序为降序，见端点判据条）；
                             中值＝两界算术平均，与端点书写顺序无关（r<1 复算：中值 (−12.04−6.02)/2＝−9.03 dB）
单侧变化（仅一侧叶变化）:    ΔR ≈ 20·lg(r_leaf)，r_leaf 为该侧面板层面密度比
r 超出 [0.5, 2] 范围:        属大幅外推，降级为"仅趋势判断"，不给确定区间
```

**Step 4 — 非面密度参数差异修正（查 M4 增益表差值）**：

| 参数差异 | 典型修正量 | 数据源等级 |
|---------|-----------|-----------|
| 空腔填充厚度增加（如玻璃棉 50→75 mm） | +1~2 dB，超过 75 mm 后增益递减 | S4 |
| 空腔深度增加（如 75→100 系列龙骨） | 约 +1 dB | S4 |
| 连接方式增强（如增设减振龙骨/减振条） | +1~2 dB | S4 |
| 连接方式机理级变化（如共用龙骨→独立双排龙骨） | +5~7 dB，但属机理级变化，建议改用 M1-M6 全模型计算 | S4 |
| 填充材料更换（容重/流阻率显著变化） | 按 M4 填充增益表差值，典型 ±1~2 dB | S3 |

**Step 5 — 结果组装**：

```
Rw_new = Rw_base + ΔR + Σ（参数差异修正）
输出区间: [Rw_base + ΔR_下界 + Σ修正_下界,  Rw_base + ΔR_上界 + Σ修正_上界]
  ΔR_下界 / ΔR_上界 ＝ Step 2「输出区间（恒升序）」的 min(ΔR_low, ΔR_high) / max(ΔR_low, ΔR_high)，为数值升序端点
  Σ修正_下界 / Σ修正_上界 ＝ Step 4 各修正项的下界之和 / 上界之和（表中各档本身即区间，如「+1~2 dB」取 1 与 2）
  保序依据：ΔR_下界 ≤ ΔR_上界 且 Σ修正_下界 ≤ Σ修正_上界 ⇒ 两端各自相加后区间仍升序；
            各修正项取同一单值时，本式退化为「加同一常数与同一 Σ修正后区间保序」的特例
  单值输出（工程推荐值）＝区间中点＝Rw_base + ΔR 中值 + Σ修正 中值，与 Step 3 的中值口径自洽
  口径声明：本组装为区间扩张（Minkowski 和），隐含各修正项可同向取极值的组合假设，端点不具统计置信含义
            （统计有效性属精度面，不由本式主张）；不得把 Σ修正 的某一中间值同时加到两端而不声明口径
            ——那会人为收窄区间并丢掉 ΔR 本身的区间宽度
```

评价量一致性：基准给出 Rw+C / Rw+Ctr 时，对同一评价量执行同法校准；不同评价量之间不可借用校准结果（对应红线 ACE-R-P2-2）。

**交叉核对要求**：M7 结果须与 M1-M6 全模型估算交叉核对。**两者差 > 5 dB 不构成自动择优规则**——差值大于 5 dB 时不得直接取任一结果（包括"看似更优"者），须先按顺序核查差异根因：① 构造是否真正同族（结构形式/支撑体系，适用前提 2）；② 是否存在机理级变化（连接方式、叶片数，适用前提 3）；③ 参数与口径（面密度计量口径按 §口径说明、r 是否超出 [0.5, 2]、修正项是否越出 M4 表适用域）；④ 模型条件（评价量同法、基准测量标准版本、M1-M6 输入完整性）。四项核查全部通过且差异能被 M1-M6 的系统性偏差（如低估空腔增益、声桥取值偏悲观）解释时，可以 M7 为主报告、同时保留 M1-M6 值并说明差异来源；任一项存疑或差异无法归因时，不单独报任一数值，输出区间/趋势并标注「交叉核对未通过」及原因。**禁止的推断**：以基准数据可信推定变体外推可信——锚点可信度不随差值大小传递到外推结果。

**精度声明**：±2-3 dB（同族构造校准）。锚定真实/权威数据，精度优于纯模型估算（±3-5 dB）；变体与基准差异越大，误差越大，r 超出 [0.5, 2] 时仅输出趋势。

**校准算例记录（2026-08-20，chatId mt0va55sgkzq0918）**：

基准：标准图集构造"75 系列轻钢龙骨 + 双面双层 12mm 耐火纸面石膏板 + 50mm 玻璃棉"，Rw = 51 dB（Rw+C = 47 dB，Rw+Ctr = 40 dB）。

变体 A：耐火板换标准纸面石膏板（12mm 面密度典型值 11.5 → 9.5 kg/m²）：

```
面板层面密度 4×11.5 = 46 → 4×9.5 = 38 kg/m²（龙骨分摊 5 kg/m² 同口径计入后 51 → 43 kg/m²）
r = 43/51 = 0.843
ΔR ∈ [min(20·lg 0.843, 40·lg 0.843), max(20·lg 0.843, 40·lg 0.843)] = [−3.0, −1.5] dB
     （此处 40·lg r 更负＝区间下界。端点一律按 min/max 取，不按位名写作 [40·lg r, 20·lg r]——
      该写法在 r<1 侧恰为升序、在 r>1 侧产出逆序区间，见 CG-20260925-003 复算 §四）
本例无 Step 4 修正项（Σ修正_下界 ＝ Σ修正_上界 ＝ 0），按 Step 5 组装：
Rw_A ∈ [51 − 3.0, 51 − 1.5] = [48.0, 49.5] dB；单值＝区间中点 ≈ 48.8 dB（工程推荐值，可读作约 49 dB）
```

变体 B：变体 A + 玻璃棉 50→75 mm（Step 4「空腔填充厚度增加」档 +1~2 dB）——按 Step 5 端点配对：
Rw_B ∈ [51 − 3.0 + 1, 51 − 1.5 + 2] = [49.0, 51.5] dB；单值＝区间中点 ≈ 50.3 dB（＝48.8 中值 + 1.5 Σ 中值）。

同构造对照（演示数据，不计为验证样本）：独立行业实测数据"75 龙骨 + 双面双层 12mm 石膏板 + 50mm 玻璃棉（24 kg/m³）"Rw ≈ 50 dB——与变体 A 单值 ≈48.8 dB 差约 1.2 dB，且落在变体 A 校准区间 [48.0, 49.5] 上沿外 0.5 dB。同构造 ACE 纯模型估算（M1-M6）为 43 dB（40-45 dB），较基准锚低 4-6 dB——**提示**简化 MSM 对双叶石膏板隔墙可能偏保守（单构造、单点比较，属方向性提示而非统计意义上的证实），有基准数据且通过上方「交叉核对要求」四类核查时 M7 作优先参考路线（路线优先≠结果自动择优）。

> **本算例的留痕缺口**：其"标准图集构造"与"独立行业实测数据"均未记录图集页码或 CMA/CNAS 检测报告编号，不满足上方输入参数表「基准数据来源」必填项，也不满足失效条件 1（基准来源不明或不可信即回退）。故本算例**仅作方法演示**，不得作为基准可信度或精度证据对外引用；本算例的一切派生读数（含上方 Rw_A／Rw_B 区间与"低 4-6 dB"的对照提示值）承继同一演示身份，不得拆出单独引用为校准证据；实际调用时基准来源缺项即按失效条件 1 回退 M1-M6 全模型。

## 三、计算流程

### 总流程

```
输入解析（ACE-IN）
  ↓
Step 0: 标准推理（调用 IC-10 → SRE）
  → 获取适用标准集 → 确定评价量
  ↓
Step 1: 模型选择
  → 根据构造类型 + 评价量选择适用模型组合
  → 存在有效基准数据（标准图集/检测报告）时，优先 M7 校准路线（路线优先仅指计算入口选择，结果仍须按 M7「交叉核对要求」处理，不构成数值自动择优）
  ↓
Step 2: 分步计算
  → 按模型组合执行计算
  ↓
Step 3: 风险识别
  → 吻合效应 + 声桥 + 缝隙 + 构造合理性
  ↓
Step 4: 输出组装（ACE-OUT）
  → 估算区间 + 风险识别 + 假设说明 + 适用边界声明
```

### 模型选择路由

| 计算类型 | 构造类型 | 适用模型组合 |
|---------|---------|------------|
| 空气声隔声 | 单层均质 | M1 + M2 + M6 |
| 空气声隔声 | 双层板+空腔 | M1 + M2 + M3 + M4 + M6 |
| 空气声隔声 | 多层复合 | M1 + M2 + M3 + M4 + M6（按层次迭代） |
| 空气声隔声 | 条板 | M1 + M2 + M6（+接缝修正） |
| 空气声隔声 | 有权威基准数据的同族变体构造 | M7 校准路线优先 + M1-M6 交叉核对（见 M7，路线优先≠结果自动择优） |
| 撞击声隔声 | 浮筑地面 | M5 + M6 |
| 撞击声隔声 | 架空地面 | M3 + M5 + M6 |

### 空气声隔声 5 步估算法

以"双层板+空腔"构造为例：

**Step 1 — 质量定律基线**：
```
m_total = m₁ + m₂
Rw_base = 20·log₁₀(m_total) + K
```

**Step 2 — MSM 共振频率**：
```
m_red = m₁·m₂ / (m₁+m₂)
f₀ = 600 / √(d_cm × m_red)
```
判定 f₀ 是否在计权范围内（<200 Hz 为有效增益区）。

**Step 3 — 空腔增益叠加**：
```
ΔR_空腔 = f(空腔深度)     // 查 M4 深度增益表
ΔR_填充 = f(填充材料, 填充率) // 查 M4 填充增益表
ΔR_解耦 = f(连接方式)       // 查 M4 解耦增益表
Rw_mid = Rw_base + ΔR_空腔 + ΔR_填充 + ΔR_解耦
```
当 f₀ ≥ 200 Hz 时，增益打折或归零。

**Step 4 — 吻合效应检查**：
```
fc₁ = M2(板材1)
fc₂ = M2(板材2)
```
评估吻合谷位置和风险等级。异质复合时检查 Δfc 是否 ≥ 300 Hz。

**Step 5 — 声桥/缝隙修正**：
```
ΔR_声桥 = f(连接类型, 节点构造)  // 查 M6 声桥表
Rw_final = Rw_mid - ΔR_声桥
```
评估密封风险，输出隔声估算区间。

### 四频段估算方法论

当输出详细度为"标准"或"详细"时，ACE 按四个频段分别估算：

| 频段 | 频率范围 | 主导因素 |
|------|---------|---------|
| 低频段 | 100-315 Hz | MSM 共振、刚度控制区 |
| 中低频段 | 315-1000 Hz | 质量控制区起始 |
| 中高频段 | 1000-3150 Hz | 质量控制区、吻合效应起始 |
| 高频段 | 3150+ Hz | 吻合效应、阻尼控制区 |

各频段的估算精度不同：中频段最可靠，低频和高频段不确定性更大。

### 撞击声估算流程

**Step 1 — 裸板基准**：
```
Ln,w_base = f(楼板面密度)  // 查 M5 裸板基准表
```

**Step 2 — 改善量**：
```
f₀ = (1/2π) × √(s / m')
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + 10
```

**Step 3 — 浮筑后估算**：
```
Ln,w_final = Ln,w_base - ΔLw
```

**Step 4 — 声桥修正**：
```
如有声桥 → Ln,w_final += ΔL_声桥（隔声变差方向）
```

## 五、评价量定义与不可混用规则

### 空气声隔声评价量

| 评价量 | 定义 | 适用场景 | 与 Rw 的关系 | 来源 |
|--------|------|---------|-------------|------|
| Rw+C | 计权隔声量 + 频谱修正量 C | 实验室，中高频噪声源（说话、电视等） | C 可正可负，故 Rw+C 可低于或高于 Rw，**不得预设 C ≥ 0**。本件 M7 校准算例的基准即 C = −4 dB（Rw 51 → Rw+C 47）。C 值来自实测频谱的单值评价结果，须随数据来源留痕 | — |
| Rw+Ctr | 计权隔声量 + 交通噪声频谱修正量 Ctr | 实验室，低频噪声源（交通、低频音乐等） | Rw+Ctr 通常比 Rw+C 低 2-5 dB | 经验归纳 |
| DnT,w+C | 标准化声压级差 + 频谱修正量 | 现场测量指标（GB 55038-2025 住宅分户墙强制） | 通常比实验室 Rw+C 低 5-10 dB | 经验归纳 |

### 撞击声隔声评价量

| 评价量 | 定义 | 适用场景 |
|--------|------|---------|
| Ln,w | 计权标准化撞击声压级 | 楼板撞击声基准评价 |
| ΔL | 撞击声改善量 | 浮筑/架空构造的改善效果评价 |

### 不可混用规则

1. **评价量之间不可直接换算**：Rw+C 不可换算为 Rw+Ctr 或 DnT,w+C，反之亦然
2. **实验室与现场不可对等**：实验室 Rw 不得直接用作现场 DnT,w 的达标判据
3. **空气声与撞击声不可混用**：Rw 和 Ln,w 评价不同物理现象，不可在同一结论中混用
4. **输出必须标注评价量**：每次输出的隔声估算区间必须明确标注使用的评价量（对应红线 ACE-R-P2-2）
5. **多评价量场景须分别输出**：当一个构造需要同时评价 Rw+C 和 Rw+Ctr 时，须分别计算并分别输出

### 评价量选择指引

| 项目类型 | 空间类型 | 推荐评价量 | 依据标准 |
|---------|---------|-----------|------|
| 住宅 | 分户墙 | DnT,w+C | GB 55038-2025 强制要求 |
| 住宅 | 分户楼板 | L'nT,w（现场标准化撞击声压级） | GB 55038-2025 第6.1.2条第2款（该款所载为现场量、不设实验室量限值，2026-09-27 条文级核验，依据载体＝shared/standards-index.md §二 序号 6 行） |
| 酒店 | 客房隔墙 | Rw+Ctr | 低频噪声敏感场景 |
| 医院 | 病房隔墙 | Rw+Ctr | 低频噪声敏感 + 隐私需求 |
| 学校 | 教室隔墙 | Rw+C | 中高频语音噪声为主 |
| 办公 | 会议室隔墙 | Rw+C | 语音隐私需求 |
| 商业 | 一般隔墙 | Rw+C | 通用场景 |

> 评价量选择由 SRE（IC-10）在项目推理阶段确定，ACE 根据传入的评价量执行对应计算，不自行选择评价量。
