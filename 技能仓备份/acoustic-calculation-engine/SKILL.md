# ACE — 装配式装修隔声计算引擎

> **现行边界（CG-20261017-008）**：先读 [reference.md「现行工程输出边界（PL-229）」](reference.md#现行工程输出边界pl-229)。当前工程输出为暂停态诊断／定性或匹配可溯源报告原量引用，不输出未验证系统 dB（含区间、频段）与精度承诺；本件下文模型能力、专业估算红线及精度表是历史研究口径，不构成恢复许可。

## 一、技能标识与角色定位

| 项目 | 定义 |
|------|------|
| 技能标识 | `ACE` |
| 技能名称 | acoustic-calculation-engine |
| 定位 | 独立补充技能——通用隔声计算基础设施（公式与判据库 ＋ 可执行程序内核 `ace_kernel.py`） |
| 核心原则 | 底层物理模型通用化，上层评价量和构造规则由各调用方技能注入 |
| 输出性质 | 当前为暂停态诊断／定性，不是系统定量预测，也非实验室检测值、现场实测值 |

ACE 不直接面向终端用户。它是被隔墙（PW）、楼地面（FL）、吊顶（CL）调用的后端，通过 IC-03/IC-08/IC-09 接收构造参数并返回适用性降级与风险识别。

> **当前承载形态（CG-20261017-008）**：`reference.md` 是判据陈述单源，`ace_kernel.py` 是可执行面，入口为 `compute_request(ic_id, request)`；`compute_airborne`／`compute_impact` 同受 PL-229 工程输出边界约束。当前合法请求的未验证系统预测必须按降级读取，不再把在册 5 步法及 M4/M6 表档组装为工程 dB。公式、常数、历史区间和算例保留，不代表其工程有效性已验证。

> **当前可达面与研究面**：接口仅保留输入校验、风险识别及正质量／有效拓扑下的质量、Hz 级 f₀ 与单板 fc 诊断；IC-09 缺宿主／叶归属字段，不给 MSM f₀。M1／M4／M5 经验式／M6／M7 纯函数供研究复算而非工程许可。M7 基准校准、M6 缝隙简化估算表、ΔL(f) 逐频带量的触发入参仍未在三契约中承载，不虚报已接入；即使宿主可手算也不能绕回定量出口。

## 二、能力边界

### ACE 提供以下计算能力

| 编号 | 能力 | 物理模型 | 适用场景 |
|------|------|---------|---------|
| C1 | 质量定律估算 | M1 | 所有板材构造的空气声隔声基础估算 |
| C2 | 吻合效应分析 | M2 | 所有薄板构造的吻合谷风险识别 |
| C3 | MSM 共振频率与空腔增益 | M3 + M4 | 双层板+空腔构造（龙骨隔墙、隔声吊顶） |
| C4 | 撞击声改善量估算 | M5 | 浮筑地面、楼面垫层 |
| C5 | 声桥/缝隙风险评估 | M6 | 所有构造的节点风险识别 |
| C6 | 敏感性分析 | M1-M6 | 关键参数变化对结果的影响趋势 |
| C7 | 基准校准估算 | M7 | 有标准图集/检测报告基准数据的同族变体构造推算（详见 §七）。**不属接口承载面**＝M7 的三条触发入参在 IC-03／IC-08／IC-09 请求面无任一承载字段，本行只述技能正文能力，不构成接口承诺（台账 PL-230） |

### ACE 不做以下事情

1. 不做"是否满足标准限值"的合规判断——该判断由调用方基于各自 A1 性能指标表完成
2. 不替代实验室检测报告或现场实测——输出始终标注"专业估算"
3. 不处理超出适用边界的构造——返回"超出模型适用范围"
4. 不覆盖现场侧向传声、门窗薄弱构件、施工质量离散等不可建模因素
5. 不包含任何标准限值，保持纯技术计算定位
6. 不将基准校准结果视为变体构造的检测值——即使基准来自标准图集或检测报告，变体构造的输出仍属"专业估算"（见 §七）

## 三、接口契约摘要

ACE 通过三组接口契约被调用，每组契约是通用 ACE-IN/ACE-OUT 在特定场景下的实例化：

| 契约 | 调用方向 | 场景 | 评价量 |
|------|---------|------|--------|
| IC-03 | PW → ACE | 隔墙空气声隔声 | Rw+C / Rw+Ctr / DnT,w+C |
| IC-08 | FL → ACE | 楼地面撞击声隔声 | Ln,w / ΔL |
| IC-09 | CL → ACE | 吊顶空气声隔声 | Rw+C / Rw+Ctr |

三组契约的请求校验、计算执行与响应组装由 `ace_kernel.py` 的 `compute_request(ic_id, request)` 承担；该入口**不抛出**降级形态，一律返回带「降级」键的 payload（形如 `{"降级": "参数不足", "说明": …, "缺失字段": […]}`），分支名与 §五 降级规则逐字对齐。行为层测试（台账 PL-031）应挂在该入口上。

**调用配方（调用方需要隔声适用性与诊断时执行；先按降级读取，不得自行改写公式或另立参考值）**：

```python
import importlib.util
from pathlib import Path
spec = importlib.util.spec_from_file_location(
    "ace_kernel", Path.home() / ".qoder/skills/acoustic-calculation-engine/ace_kernel.py")
ace = importlib.util.module_from_spec(spec)
spec.loader.exec_module(ace)
result = ace.compute_request("IC-03", request)   # request 形如契约件 IC-03-Request
```

返回体只有两种形态（PL-229 暂停期三枚契约现读一律走降级形态，正常形态待定量出口恢复）：正常＝带 `计算结果`／`风险识别`／`关键假设说明`／`适用边界声明`／`超出范围提示`
的 ACE-OUT；降级＝带 `降级` 键的 payload（分支串与 §五 逐字对齐）。`compute_request` 不抛出，
**调用方不得把降级 payload 读作数值结果**；结果整合进本技能输出时须带出
`ace.output_nature_note()` 的性质声明（ACE-R-P0-1；暂停期该串为「仅诊断、未输出系统隔声定量结果」）。内核文件缺席即
`FileNotFoundError`——**不得为兜底而在调用方内另写一套公式**，那正是 PL-054 甲支所消除的
「测试侧第二副本」形态（A3/F2）的重演。

### 通用输入结构（ACE-IN 三层架构）

1. **调用方标识层**：技能标识 + 计算类型 + 评价量
2. **构造描述层**：构造类型 + 板材层 + 空腔层 + 支撑/连接系统 + 密封方式
3. **计算选项层**：输出详细度 + 频率范围

各调用方的最小参数集详见 interface-contracts.md 对应契约。参数不足时 ACE 返回"参数不足，无法执行有效计算"并列出缺失字段。

### 通用输出结构（ACE-OUT）

```
计算结果
├─ 隔声估算区间 {下限, 上限, 评价量, 置信度}
└─ 频段分析 [{中心频率, 估算隔声量, 吻合谷标记}]
风险识别
├─ 吻合效应风险 {等级, 风险频率范围, 说明}
├─ 声桥风险等级 {等级, 风险点, 说明}
├─ 密封评估 {结论, 依据, 改进建议}
└─ 构造合理性意见 {结论, 风险点, 优化方向}
敏感性分析（标准/详细模式）
关键假设说明
适用边界声明
超出范围提示（如有）
```

## 六、与 SRE 的集成

ACE 的计算流程以标准推理为前置步骤：

```
Step 0: 调用 IC-10（SRE 场景推理）
         ↓ 获取适用标准集
Step 1: 根据项目类型 + 空间类型确定评价量
         空气声场景：
           住宅分户墙 → DnT,w+C（GB 55038-2025 强制）
           酒店/医院客房 → Rw+Ctr（低频敏感场景）
           一般场景 → Rw+C
         撞击声场景：
           住宅分户楼板 → 达标判据量 L'nT,w（GB 55038-2025 强制要求承载条文＝第6.1.2条第2款、现场量；本引擎产出为实验室量族估算 Ln,w／ΔL，不得以估算替代现场量判定）
           面层改善评价 → ΔL
Step 2: 根据评价量选择计算模型组合
         空气声隔声 → M1 + M2 + M3/M4 + M6
         撞击声隔声 → M5 + M6
         提供有效基准数据时 → M7 校准路线优先，M1-M6 交叉核对（路线优先≠结果自动择优，见 §七）
         〔M7 不属接口承载面：基准构造／基准隔声量／基准数据来源三条入参经会话文本传入，
         　IC-03／IC-08／IC-09 请求面无对应字段，故本行的「优先」只在技能正文层生效，
         　不经 compute_request 入口（台账 PL-230）〕
Step 3: 执行分步计算 → 组装 ACE-OUT
```

ACE 不自行判断适用标准——标准识别由 SRE 完成。ACE 仅在接收到评价量后执行对应的计算模型。

## 七、基准校准模式（M7）

### 模式定位

当调用方提供已知构造的权威隔声基准数据时，ACE 以该数据为锚点，通过面密度比对与参数差异修正，反推同族变体构造的隔声量。该模式不做从零理论计算，而是「锚定 + 差分外推」，用于规避纯模型估算对特定构造族的系统性偏差（演示对照提示：简化 MSM 对双叶石膏板隔墙偏保守 4-6 dB——该值派生自 reference.md M7 校准算例中未记录图集页码／报告编号的对照数据，属方法演示读数，不得拆出引用为已校准证据）。

方法论依据：ISO 12354-1:2017 估算框架以构件实验室实测数据为输入估算建筑隔声性能；基准 Rw 须按 GB/T 45305.2-2025（现行，全部代替已废止的 GB/T 19889.3-2005）测量、GB/T 50121-2005 评价，或出自出版的标准设计图集；按 GB/T 19889.3-2005 测得的历史图集/检测报告基准仍可作为锚点，但须在假设说明中注明测量标准版本。

### 触发条件

调用方同时提供：① 基准构造描述 + 基准隔声量（Rw / Rw+C / Rw+Ctr 等，评价量须明确）；② 基准数据来源（标准图集名称/页码，或 CMA/CNAS 检测报告编号）；③ 变体构造描述。

> **承载面声明（CG-20261017-009／台账 PL-230 乙支）**：上述三条入参**不经接口传入**＝IC-03／IC-08／IC-09 的「请求参数约束」表内「基准／图集／检测报告」类字段现读命中 **0**（本批开工按实复算，三枚各 0），内核 `IC_FIELD_SPECS` 三枚请求面同口径 0，`compute_request` 因此无 M7 请求入口（`m7_calibrate` 只作库函数供研究复算，不经任何在册契约被调用）。⇒ **M7 由本件正文按会话文本执行，不属接口承载面**；其三条适用前提（来源可信／构造同族／无机理级变化）**无机检面**，须由调用方在会话内逐条披露并承担，不得读作"已接入接口的可算能力"。补齐承载字段的路线（新增可选请求字段＋按 §4.3 升 minor）在册于 PL-230 (甲) 支，本批未采。

### 适用前提（三条须同时满足）

1. **基准来源可信**：标准设计图集或 CMA/CNAS 检测报告，来源信息可记录；来源不明或无法溯源的不予校准。
2. **构造同族**：基准与变体的结构形式（单叶 / 双叶+空腔等）与支撑体系类型相同，差异限于板材面密度（板型/厚度/层数）、空腔填充等参数。
3. **无机理级变化**：连接方式未改变（如共用龙骨→独立双排龙骨）、叶片数量未增减。机理级变化使面密度比对失效，须回退 M1-M6 全模型计算。

### 方法概要

```
r = m_new / m_base          （面密度比，宜按两侧面板层计）
单叶构造:      ΔRw = 20·lg(r)
双叶构造下限:  ΔRw_low  = 20·lg(r)    （质量定律主导）
双叶构造上限:  ΔRw_high = 40·lg(r)    （理想空腔区、对称双叶、无声桥）
对称变体取区间中值，输出区间（端点一律按数值升序，即 [min(ΔRw_low, ΔRw_high), max(ΔRw_low, ΔRw_high)]，r<1 时不得按位名写作 [low, high]）；单侧变化按该侧比值取 20·lg
Rw_new = Rw_base + ΔRw + Σ（非面密度参数差异修正，查 M4 增益表差值）
输出区间按端点配对：下界端加 Σ修正_下界（各修正项下界之和）、上界端加 Σ修正_上界（各修正项上界之和）；
  定义与保序依据见 reference.md M7 Step 5，本件不重复承载
```

物理依据：质量-空气-质量共振频率以上的质量控制区，解耦双叶构造隔声量近似两叶之和（R ≈ R₁+R₂），两侧面密度同步缩放系数 r 时增益上界为 40·lg(r)；轻钢龙骨等声桥使实际值落在 20·lg 与 40·lg 之间（工程取中值）。完整公式、参数表与算例见 reference.md M7。

### 交叉核对要求

M7 结果须与 M1-M6 全模型估算交叉核对。两者差 > 5 dB 时**不构成自动择优**：不得直接优先报 M7（数据锚点可信不等于变体外推可信），须先核查构造同族、机理级变化、参数与口径、模型条件四类根因（完整规则见 reference.md M7「交叉核对要求」）；核查全过且差异能被 M1-M6 系统性偏差（通常为低估空腔增益、声桥取值偏悲观）解释时以 M7 为主报告并保留 M1-M6 值及差异来源说明，否则不单独报任一数值、降级为区间/趋势并标注「交叉核对未通过」及原因。

### 失效与降级

基准来源不明、构造族不同、或面密度比 r 超出 [0.5, 2] 外推区时，回退 M1-M6 模型估算，标注「基准校准不适用」及原因（见 §五 降级规则）。

### 输出要求与红线映射

- 输出须列明：基准来源、基准构造与变体构造对比、面密度计算、ΔRw 区间、校准结果区间（ACE-R-P2-1 关键假设记录）
- 校准结果标注「基于基准校准的专业估算」及对应评价量（ACE-R-P0-1 输出性质、ACE-R-P2-2 评价量标注）
- 变体构造的确定性数值仍须以同构造检测报告为准，校准结果不得表述为变体构造的检测值
