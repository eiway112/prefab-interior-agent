## 一、整体卫浴产品形态索引

| 构造形式 | 核心特征 | 典型应用 | 选型关键维度 |
|---------|---------|---------|------------|
| SMC整体卫浴 | 一体模压防水底盘+SMC墙顶板 | 酒店、公寓、保障房、学校宿舍 | 底盘厚度、墙板连接方式、密封体系、模数适配 |
| 彩钢板整体卫浴 | 彩钢复合板墙板+防水底盘 | 中高端酒店、长租公寓 | 彩钢板芯材、表面涂层、接缝密封、色彩定制 |
| 瓷砖饰面整体卫浴 | 防水底盘+轻钢龙骨+瓷砖/岩板饰面 | 住宅精装、高端酒店 | 底盘与龙骨连接、饰面荷载、防水节点 |
| 干法装配式卫浴 | 干法基层+独立防水层+饰面板 | 异形空间、改造项目 | 基层板材质、防水层做法、饰面可逆性 |

## 二、SMC整体卫浴（示例条目）

### 2.1 经济型 SMC 整体卫浴

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 酒店客房卫生间、公寓卫生间、学校宿舍卫生间 |
| 常见模数 | 1200×1500 / 1200×1800 / 1500×1800 mm |
| 底盘 | SMC一体模压，厚度≥3.5mm（*示例值*） |
| 墙板 | SMC模压墙板，厚度≥2.5mm（*示例值*） |
| 顶板 | SMC模压顶板或铝扣板集成吊顶 |
| 防水等级 | I级（依赖底盘整体密封性） |
| 排水坡度 | 底盘工厂模压成型，一般区≥1%，淋浴区≥1.5% |
| 安装工期 | 4-8h/套（*经验数据*） |
| 优势 | 防水可靠、工期短、标准化程度高、维护成本低 |
| 局限 | 造型单一、尺寸受限、质感一般 |
| 数据时间 | 2026-08 |

### 2.2 标准型 SMC 整体卫浴

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 标准酒店、长租公寓、保障房 |
| 常见模数 | 1500×1800 / 1500×2100 / 1800×2100 mm |
| 底盘 | SMC一体模压，可选配架空高度 80-150mm |
| 墙板 | SMC墙板，表面可选覆膜/喷涂 |
| 顶板 | 集成吊顶（铝扣板/SMC顶板） |
| 设备接口 | 预留坐便器坑位、洗面器给排水、淋浴花洒、暖风机电源 |
| 优势 | 性价比高、适配批量项目 |
| 局限 | 异形空间适配性差 |
| 数据时间 | 2026-08 |

## 三、彩钢板整体卫浴（示例条目）

### 3.1 中高端彩钢板整体卫浴

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 中高端酒店、品牌长租公寓 |
| 常见模数 | 1500×1800 / 1800×2100 mm |
| 底盘 | SMC/FRP防水底盘，可架空安装 |
| 墙板 | 彩钢复合板（面板+芯材+背板），厚度≥25mm（*示例值*） |
| 表面涂层 | 聚酯/氟碳涂层，耐擦洗、防霉 |
| 防水等级 | I级 |
| 色彩定制 | 可定制色卡，满足酒店风格需求 |
| 优势 | 装饰效果较好、色彩丰富、可定制 |
| 局限 | 接缝需密封处理、成本较 SMC 高 |
| 数据时间 | 2026-08 |

## 四、瓷砖饰面整体卫浴（示例条目）

### 4.1 住宅精装型瓷砖饰面整体卫浴

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 住宅精装、高端酒店 |
| 常见模数 | 非标定制为主 |
| 底盘 | 组装式防水底盘，预留排水接口 |
| 骨架 | 轻钢龙骨或铝型材骨架 |
| 饰面 | 瓷砖/岩板/硅酸钙饰面板 |
| 防水层 | 底盘本体防水+节点密封 |

| 优势 | 装饰效果接近传统装修、个性化强 |
| 局限 | 工期较长、接缝多、防水依赖施工质量 |
| 数据时间 | 2026-08 |

## 五、装配式厨房产品形态

### 5.1 集成橱柜系统

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 住宅、公寓 |
| 构成 | 柜体+门板+台面+五金 |
| 柜体材质 | 防潮刨花板/多层板/不锈钢（*示例*） |
| 台面材质 | 石英石/岩板/不锈钢 |
| 关键接口 | 水槽给排水、燃气灶预留、油烟机电源、洗碗机电源/排水 |
| 优势 | 工厂预制、现场组装、精度高 |
| 局限 | 非标空间适配成本较高 |

### 5.2 模块化厨房单元

| 项目 | 参数/说明 |
|------|----------|
| 适用空间 | 公寓、酒店、模块化建筑 |
| 构成 | 整体厨房模块（含橱柜、水槽、部分设备） |
| 安装方式 | 工厂整体预制，现场吊装就位 |
| 关键接口 | 给水总接口、排水总接口、电源总接口、排烟接口 |
| 优势 | 工期极短、质量可控 |
| 局限 | 运输尺寸受限、现场条件要求高 |

## 六、选型速查表

| 场景 | 推荐构造形式 | 核心理由 |
|------|------------|---------|
| 经济型酒店/公寓批量项目 | SMC整体卫浴 | 成本低、防水可靠、工期短 |
| 中高端酒店/长租公寓 | 彩钢板整体卫浴 | 装饰效果较好、可定制 |
| 住宅精装/高端项目 | 瓷砖饰面整体卫浴 | 个性化强、接近传统装修 |
| 异形空间/改造项目 | 干法装配式卫浴 | 灵活度高、适配性强 |
| 公寓/模块化建筑厨房 | 模块化厨房单元 | 整体预制、快速安装 |
| 普通住宅厨房 | 集成橱柜系统 | 性价比高、选择面广 |
