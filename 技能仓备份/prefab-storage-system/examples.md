## 示例 1：B1 选型决策树（长租公寓玄关柜标准化）

**用户输入**：长租公寓项目，想尽量标准化收纳柜，玄关柜怎么选能减少非标？

**输入分类**：C 类对比选型。

**应答示例**：

```markdown
## 需求概述
- 项目类型：长租公寓
- 空间：玄关
- 核心诉求：标准化、减少非标、控制成本
- 关键约束：通风、换鞋、挂衣、与门套关系

## 系统选型对比

| 维度 | 标准模块化玄关柜 | 非标定制玄关柜 |
|------|----------------|---------------|
| 宽度模数 | 600/800/900mm | 按现场任意尺寸 |
| 深度 | 300~350mm | 按现场调整 |
| 标准化率 | ≥90% | ≤50% |
| 成本 | 低 | 高 |
| 工期 | 短 | 长 |
| 推荐度 | ★★★★★ | ★★☆☆☆ |

## 推荐方案
长租公寓玄关推荐 **标准模块化玄关柜**。

**依据**：
- 户型重复率高，标准模块可批量下单
- 非标比例控制在 10% 以内（调节板/收口条消化）
- 便于后期维护更换

## 模块化配置

| 部品 | 规格 | 数量 | 数据来源 |
|------|------|------|---------|
| 玄关柜主体 | 900mm（宽）×350mm（深）×2400mm（高） | 1 | S2：行业通用做法 |
| 鞋柜区 | 600mm×350mm，层板间距 150~200mm | 1 | S2：行业通用做法 |
| 换鞋凳 | 800mm×400mm×450mm | 1 | S3：经验数据 |
| 挂衣区 | 宽度≥600mm，高度 1200~1500mm | 1 | S2：行业通用做法 |
| 调节板 | 宽度 30~100mm | 按需 | S2：行业通用做法 |

## 风险提示
- 墙面平整度、垂直度须现场复测
- 插座/照明点位须与柜体布局协调
- 项目所在地如有更严格地方标准，应优先执行
```

## 示例 2：B2 方案验证协议执行（壁挂衣柜）

**用户输入**：卧室要做壁挂衣柜，墙体是轻钢龙骨隔墙，请帮我验证方案。

**输入分类**：A 类方案验证。

**应答示例**：

```markdown
## B2 方案验证报告

### 1. 输入信息
- 项目类型：住宅
- 空间类型：卧室
- 柜体类型：壁挂衣柜
- 墙体类型：轻钢龙骨隔墙
- 柜体规格：1800mm（宽）×600mm（深）×2400mm（高）

### 2. 逐项验证

| 检查项 | 输入值 | 规范/要求 | 结论 | 备注 |
|--------|--------|----------|------|------|
| 柜体环保等级 | 未说明 | 室内使用≥E1 级 | ❓ 待确认 | 须补充板材环保等级 |
| 壁挂基层承载力 | 轻钢龙骨隔墙 | 轻质隔墙须加固处理 | ⚠️ CONDITIONAL | 须由结构工程师确认加固方案 |
| 柜体深度 | 600mm | 挂衣区深度≥500mm | ✅ PASS | S2：行业通用做法 |
| 固定件 | 未说明 | 须满足结构验算确定的锚固承载要求 | ❓ 待确认 | 须补充固定件规格、数量及验算依据 |
| 防潮处理 | 卧室干燥区 | 普通人造板即可 | ✅ PASS | S2：行业通用做法 |

### 3. 验证结论
**CONDITIONAL-PASS**

需整改/确认项：
1. 补充板材环保等级（不得低于 E1 级）
2. 轻质隔墙须由结构工程师确认加固方案
3. 补充固定件规格、数量及拉拔试验要求

### 4. 风险提示
- 壁挂柜体承载力须由注册结构工程师验算确认
- 本验证为装配式装修接口级复核，不替代结构设计
```

## 示例 3：P0 红线触发处理（忽略壁挂承载力验算）

**用户输入**：壁挂衣柜直接打膨胀螺栓固定在轻钢龙骨隔墙上，应该没问题吧？

**应答示例**：

```markdown
[ST-R-P0-1 触发] 严禁忽略壁挂柜体承载力验算

轻质隔墙不可直接作为壁挂柜体锚固基层，必须采取加固处理并由结构工程师确认承载力满足设计荷载。

**因此，该方案不可直接实施。**

**必须完成的事项**：
- 由注册结构工程师验算墙体承载力
- 按结构加固方案施工（如背板加固、预埋钢架等）
- 加固完成后进行拉拔试验或荷载试验验证

**本技能可协助内容**：
- 柜体模数与空间适配
- 固定点位置与柜体结构协调
- 安装顺序与基层条件确认
```

## 示例 4：P0 红线触发处理（环保等级不足）

**用户输入**：为了控制成本，儿童房柜体想用 E2 级板材，可以吗？

**应答示例**：

```markdown
[ST-R-P0-2 触发] 严禁忽略环保等级要求

室内使用的人造板及其制品甲醛释放量不得低于 E1 级（GB 18580-2025）。儿童房建议优先选用 E0 或 ENF 级。

**因此，不建议采用 E2 级板材。**

如需控制造价，可在满足环保要求的前提下考虑：
- 柜体内部结构件选用 E1 级，可见面板选用 E0 级
- 减少非必要装饰件
- 选用性价比高的标准模块

具体选材须以设计文件和检测报告为准。
```

## 示例 5：跨技能路由（橱柜与厨卫系统协同）

**用户输入**：厨房橱柜布局想和燃气、给排水点位一起定，你们能一起做吗？

**应答示例**：

```markdown
本技能专注于收纳系统接口协调，厨房燃气设计、给排水系统设计须由专业工程师完成。

**建议下一步**：
- 厨房设备/管线/防水接口协调 → 调用 **prefab-bathroom-kitchen-system**
- 橱柜与吊顶/墙面/地面收口 → 继续由本技能处理
- 燃气设计 → 须由具备燃气设计资质的单位完成

**本技能可协助内容**：
- 橱柜模数、布局与空间适配
- 吊柜壁挂承载力条件确认
- 橱柜安装顺序与成品保护
```

## 示例 6：数据分级标注示例

**用户输入**：衣柜层板跨度 900mm，厚度 18mm 够吗？

**应答示例**：

```markdown
| 项目 | 说明 | 数据来源 |
|------|------|---------|
| GB/T 3324-2024 要求 | 搁板弯曲挠度变化值≤0.5%（≤0.5% 即 ≤L/200）；均布荷载下与 L 为跨度两支属试验方法侧读法——该版不设跨度定义（`跨度` 全份计数 0），6.6.5 柜类强度和耐久性整体委托 GB/T 10357.5—2023，故挠度与跨度的换算属该试验方法标准侧（该试验方法标准未取件） | S1：GB/T 3324-2024 5.6 表6 搁板弯曲挠度变化值行（一般项目，条文级核验 2026-10-01，全份已逐字核验 2026-10-02）；原「卸载后无永久变形」一支该版未载，撤为无依据表述 |
| 900mm 跨度建议 | 18mm 板材可能挠度偏大，建议加厚至 25mm 或增加中间支撑 | S3：经验数据 |
| 最终判定 | 须以厂家型式检验报告和结构设计文件为准 | 待确认 |

> S3 级为行业经验参考值，不得作为设计计算依据；具体项目应以设计文件和检测报告为准。
> 数据分类与取证判据见 `shared/data-classification.md`；本段禁令对已达其 §一 该类满判据的 B／C／D 类数据不适用（效力关系见其 §四.2）。
```
