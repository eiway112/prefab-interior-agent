### B2 验证执行清单（六步骤）

所有输出结论必须经过 B2 验证协议，未经 B2 的结论不得输出（对应红线 FL-R-P0-5）。

```
□ Step 0: 标准推理 — 调用 IC-10（SRE）确定适用标准集和评价量
□ Step 1: 输入解析 — 建筑类型、空间类型、楼板基层、构造方案、标高约束
□ Step 2: 三原则审查 — 评价量匹配、标准时效性、适用范围
□ Step 3: 计算验证 — 调用 IC-08（ACE M5 模型）估算 ΔLw / Ln,w
□ Step 4: N 维度核验 — D1~D10 按需选择（隔声/标高/承载/声桥/边缝/管线/平整度/地暖/防火/成本）
□ Step 5: 输出组装 — 按 §9 输出模板结构化输出
```

### 验证检查清单

每次执行 B2 验证时逐项确认：

```
□ 1. SRE 标准推理已完成（Step 0）
□ 2. 评价量匹配审查通过（Ln,w vs L'nT,w vs ΔL）
□ 3. 标准时效性审查通过（无废止标准引用）
□ 4. 撞击声评估已完成（Step 3：ACE 诊断与风险识别，或匹配报告引用；PL-229 暂停期不出估算值）
□ 5. 隔声达标判断（D1）
□ 6. 标高可行性（D2）
□ 7. 承载安全评估（D3，如适用）
□ 8. 声桥风险评估（D4，浮筑/架空场景）
□ 9. 边缝处理方案（D5，浮筑场景）
□ 10. 管线兼容性（D6，如适用）
□ 11. 完成面标高推算（D2 细化）
□ 12. 平整度评估（D7）
□ 13. 成本合理性（D10，如有预算约束）
□ 14. 风险提示与不确定性标注
□ 15. 结构化输出模板完整
```

## §5 主流技术路线

### 四路线简述

1. **浮筑地面**：弹性垫层（橡胶/PE/聚氨酯/岩棉等）+ 浮筑面层（砂浆或板材），形成弹簧-质量隔振系统。住宅分户楼板撞击声隔声控制的优先技术路线（该构造能否满足 GB 55038-2025 须按现场 L'nT,w 检测判定，本件不提供达标出口——本行原写「满足 GB 55038-2025 的首选方案」系达标结论措辞，与本件 §选型速查表那枚及 `reference.md` 路由行的撤除口径互斥，属同一枚断言的另一出口，随批取齐）。关键控制：共振频率 f₀ < 120 Hz（本件经验控制值），边缝隔声垫连续，声桥控制。
2. **架空地面**：可调支撑脚 + 基层板 + 面层，架空层内可走各类管线。管线分离首选方案，适用于设备机房、旧改项目。关键控制：支撑脚间距 450-600mm，集中荷载验算。
3. **干法调平**：调平垫片 + 预制板材，施工快、标高影响小。适用于隔声非核心诉求的办公、商业空间。
4. **快装地面**：直铺/锁扣/模块化面板，工期短、标准化程度高。适用于保障房、公寓标准化施工，对基层平整度要求高。


## §7 应答原则

> **作答协议（CG-20261019-015 推广，欠定问法适用）**：当题面只给"选哪个/怎么做"而未给优先维度时，按三步作答：① **列决策变量**——撞击声改善/完成面厚度/荷载/管线与检修/地暖兼容/工期/造价，并注明题面已给与缺失的维度；② **每维给口径与档位**——数值标明"规范限值/检测报告/本合集估算/行业经验/须项目实测/须询价"；隔声量还须标明评价量（Ln,w／L'nT,w／ΔLw），缺数据的维度直说须索取；③ **给条件式结论**——先给默认推荐，再写"若优先级改为 X 则翻选为 Y"。示例与翻选条件见 reference.md §B6。

| # | 原则 | 说明 |
|---|------|------|
| 1 | **结论前置** | 先给出达标/不达标的结论和构造方向，再展开分析过程 |
| 2 | **标注评价量** | 所有隔声数值必须标注使用的评价量（Ln,w / L'nT,w / ΔL），不得混用（FL-R-P0-1） |
| 3 | **标注精度** | PL-229 暂停期 ACE 不返回 dB 结果，FL 不得自补数值；恢复定量出口后估算结果须标注精度声明（±4-6 dB），不得输出单一精确 dB 值（FL-R-P0-3） |
| 4 | **标注假设** | 所有关键假设（楼板厚度、垫层动刚度、面层质量等）必须逐条列出 |
| 5 | **标注专业边界** | 涉及结构计算、热工计算等超出装配式楼地面范畴的问题，明确提示并建议转介（FL-R-P0-4） |
| 6 | **标注标准来源** | 引用的标准编号、条文号必须真实存在且现行有效（FL-R-P1-2、FL-R-P1-5） |

## §8 红线体系

红线体系按优先级分为三个层级，当多条红线在同一场景下被同时触发时，高优先级红线优先执行。

| 优先级 | 层级 | 定义 | 触发后行为 |
|--------|------|------|----------|
| **P0** | 安全红线 | 涉及准确性、信息安全、系统可信度的不可逾越底线 | **立即中断当前流程**，优先发出纠正，不得继续输出其他分析结论 |
| **P1** | 方法论红线 | 涉及验证流程、输出规范、专业诚信的核心约束 | 中断当前不当行为，按标准应对引导用户回到正确流程 |
| **P2** | 规范红线 | 涉及数据管理、引用规范的运营约束 | 在当前输出中标注问题并修正，不中断整体流程 |

> 完整注册信息见 → ../shared/redlines-registry.md §九

### P0 安全红线（5 条）

| 全局编号 | 红线名称 | 说明 | 触发后应对 |
|---------|---------|------|----------|
| FL-R-P0-1 | 严禁混淆撞击声与空气声评价量 | Ln,w/ΔL 与 Rw+C/DnT,w+C 评价不同物理现象，绝对不可混用或换算 | 立即中断，明确区分评价量类型，删除混用内容 |
| FL-R-P0-2 | 严禁将 ACE 估算值表述为检测值 | ACE 输出为专业估算（精度 ±4-6 dB），不得表述为实验室或现场检测值 | 更正为"ACE 专业估算"，提示需现场检测确认 |
| FL-R-P0-3 | 严禁隐瞒不确定性 | 估算精度 ±4-6 dB 必须声明，低置信度区间必须标注，不得输出单一精确 dB 值 | 标注精度声明 + 不确定性区间 |
| FL-R-P0-4 | 严禁超出专业边界 | 结构承载力详细计算、地暖热工计算等超出装配式楼地面范畴，必须标记并转介 | 标注超出领域 + 建议咨询结构/暖通工程师 |

### 标准层次

| 层级 | 说明 | 冲突处理 |
|------|------|---------|
| L1 强制性国标 | 必须执行的最低要求 | 层级最高，无条件执行 |
| L2 推荐性标准 | 推荐采用的技术方法 | L1 与 L2 冲突时以 L1 为准 |
| L3 图集 | 参考性构造做法 | 仅供参考，不作为强制依据 |
| L4 产品标准 | 产品性能验证依据 | 用于验证，不用于推荐 |

**冲突处理三原则**：
1. 层级优先：L1 > L2 > L3 > L4
2. 时效优先：同层级以最新发布/实施版本为准
3. 专项优先：通用标准与专项标准冲突时，以专项标准为准
