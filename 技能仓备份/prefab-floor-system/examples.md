## 示例 1：住宅分户楼板浮筑地面（GB 55038-2025 达标验证）

### 场景描述

新建住宅项目，结构楼板为 120mm 现浇钢筋混凝土，设计方提出采用浮筑地面构造以满足 GB 55038-2025 对分户楼板撞击声的强制性要求（L'nT,w ≤ 65 dB）。拟定构造为：橡胶隔声垫（示例动刚度 s=15 MN/m³，厚 8mm）+ 50mm 水泥砂浆浮筑层 + 10mm 瓷砖面层。需验证该构造是否达标，并完成全流程 B2 验证。

### 方法论运作过程

#### Step 0: 标准推理

**IC-10 调用**（SRE 场景推理引擎）：

```
请求参数：
  project_type: "residential"（新建住宅）
  space_type: "dwelling_unit_floor"（分户楼板）
  construction_type: "floor"
  performance_domains: ["impact_sound"]

IC-10 返回结果：
  适用标准集：
    - GB 55038-2025《住宅项目规范》（L1 强制）— 分户楼板 L'nT,w ≤ 65 dB
    - GB/T 50121-2005《建筑隔声评价标准》（L2 推荐）— 评价量定义
    - GB/T 19889.7-2022（L2 推荐）— 现场检测方法
  强制评价量：L'nT,w（现场标准化撞击声压级，T₀=0.5s）
  限值：≤ 65 dB
  标准时效：GB 55038-2025 于 2025-05-01 起实施，现行有效
  注意：GB 50118-2010 中住宅隔声条文已被 GB 55038-2025 替代（FL-R-P1-2）
```

#### Step 1: 输入解析

| 参数 | 值 | 来源 |
|------|-----|------|
| 建筑类型 | 新建住宅 | 用户提供 |
| 空间类型 | 分户楼板 | 用户提供 |
| 楼板基层 | 120mm 现浇钢筋混凝土 | 设计图纸 |
| 基层面密度 | ~288 kg/m² | 查表（reference.md A2 裸板基准） |
| 裸板 Ln,w 基准 | 76-80 dB（取中值 78 dB） | reference.md A2 |
| 弹性垫材料 | 橡胶隔声垫（示例数据） | 用户指定 |
| 弹性垫动刚度 s | 15 MN/m³ = 15×10⁶ N/m³ | 用户提供（示例值） |
| 弹性垫厚度 | 8mm | 用户提供 |
| 浮筑层 | 50mm 水泥砂浆 | 用户提供 |
| 砂浆面密度 | ~85 kg/m²（50mm × 1700 kg/m³） | 计算 |
| 面层 | 10mm 瓷砖 | 用户提供 |
| 瓷砖面密度 | ~22 kg/m² | 查表 |
| 浮筑层总面密度 m' | 85 + 22 = 107 kg/m²（取 ~95 kg/m² 含砂浆实际密度修正） | 计算 |
| 标高约束 | 未提出特殊限制 | 用户提供 |

#### Step 2: 三原则审查

| 审查原则 | 审查结果 | 说明 |
|---------|---------|------|
| 评价量匹配 | ✓ 通过 | 住宅分户楼板 → 使用 L'nT,w，未混用 Ln,w 或 Rw（FL-R-P0-1 未触发）；L'nT,w 不提供数值估算（两量间无换算式），达标以现场检测判定，已在 Step 3 披露 |
| 标准时效性 | ✓ 通过 | GB 55038-2025 现行有效（2025-05-01 起实施），未引用废止的 GB 50118-2010 住宅条文（FL-R-P1-2 未触发） |
| 适用范围 | ✓ 通过 | 浮筑地面适用于住宅分户楼板隔声，构造类型匹配 |

#### Step 3: 计算验证（IC-08）

**ACE IC-08 调用过程**：

```
请求参数：
  base_slab: { type: "RC", thickness: 120mm, density: 288 kg/m² }
  resilient_layer: { material: "rubber_pad", s: 15e6 N/m³, thickness: 8mm }
  floating_layer: { type: "mortar", thickness: 50mm, density: 85 kg/m² }
  finish_layer: { type: "ceramic_tile", thickness: 10mm, density: 22 kg/m² }
  total_mass_m_prime: 95 kg/m²
  evaluation_quantity: "Ln,w"
```

**M5 模型手算验证**（ACE 降级策略备用）：

**① 共振频率 f₀ 计算**：

```
f₀ = (1/2π) × √(s / m')
   = (1/2π) × √(15×10⁶ / 95)
   = (1/2π) × √(157895)
   = (1/2π) × 397.4
   ≈ 63.3 Hz
```

f₀ ≈ 63 Hz → **优秀**（f₀ < 80 Hz，共振频率远低于撞击声主要频率范围 100-3150 Hz，全频段有效改善）

**② 改善量 ΔLw 估算**：

```
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C
    = 18·log₁₀(95) - 10·log₁₀(15) + 10
    = 18 × 1.978 - 10 × 1.176 + 10
    = 35.6 - 11.8 + 10
    ≈ 33.8 dB
```

**③ 浮筑后撞击声压级估算**：

```
Ln,w(裸板) ≈ 78 dB（120mm 钢筋混凝土基准中值）
Ln,w(浮筑) ≈ 78 - 33.8 ≈ 44.2 dB
```

取区间估算：Ln,w(浮筑) ≈ 42-46 dB

**④ 达标判断**：

```
Ln,w(浮筑) ≈ 42-46 dB → L'nT,w 不提供数值估算（实验室 Ln,w 与现场 L'nT,w 之间无换算式，区间加宽亦无依据）
限值：L'nT,w ≤ 65 dB
结论：不作达标判定——现场 L'nT,w 无数值出口，不作与限值的数值比较；达标须以现场 L'nT,w 检测判定
```

精度声明：ACE 专业估算，精度 ±4-6 dB，最终确认应以现场 L'nT,w 检测为准。

#### Step 4: N 维度核验

| 维度 | 编号 | 结果 | 说明 |
|------|------|------|------|
| 隔声 | D1 | ⚠ 待现场检测 | L'nT,w 不提供数值估算（两量间无换算式），达标须现场 L'nT,w 检测判定 |
| 标高 | D2 | ✓ | 构造总厚度 = 8 + 50 + 10 = 68mm，需确认与设计标高协调 |
| 承载 | D3 | ✓ | 恒荷载 ≈ 1.17 kN/m²，住宅活荷载标准值 2.0 kN/m²，初步判断可满足（详细计算由结构工程师完成） |
| 声桥 | D4 | ⚠ 中风险 | 需关注：边缝隔声垫连续性、管道穿越套管、门槛隔声断开（详见声桥风险评估） |
| 边缝 | D5 | ✓ | 要求边缝隔声垫连续设置，宽度 ≥ 面层厚度（68mm），材质与弹性垫匹配 |
| 管线 | D6 | ✓ | 管线预埋在结构楼板内，无需穿越浮筑层，无额外声桥风险 |
| 平整度 | D7 | ✓ | 面层为瓷砖：表面平整度 ≤2.0mm/2m、接缝高低差 ≤0.5mm（GB 50209-2010 表6.1.8 陶瓷锦砖／高级水磨石板块／陶瓷地砖档，2026-09-27 官方出版物逐格核验，正文第 45 页／PDF p058）；水泥砂浆找平面按表5.1.7 ≤4mm/2m（2026-09-25 官方出版物核验。原载水泥砂浆面 ≤3mm 无该档对应——表5.1.7 砂浆档为 4mm，3mm 档系普通水磨石；如需采用 ≤3mm 属企业内控加严值） |
| 地暖 | D8 | — | 本场景无地暖，不适用 |
| 防火 | D9 | ✓ | 水泥砂浆 + 瓷砖均为 A 级不燃材料，满足住宅楼板防火要求 |
| 成本 | D10 | — | 用户未提出预算约束，不评估 |

**声桥风险评估（D4 细化）**：

| 风险点 | 风险等级 | 控制措施 |
|--------|---------|---------|
| 边缝未设隔声垫条 | 高 | 四周墙根设置连续隔声垫条，宽度 ≥ 68mm，上翻至墙面 |
| 管道穿越浮筑层 | 中 | 如有管道穿越，设弹性套管 + 密封胶，套管与浮筑层间留 ≥ 10mm 间隙 |
| 门槛处浮筑层连续 | 中 | 门洞口处设隔声断开缝，填充弹性密封材料 |
| 踢脚线刚性连接 | 低 | 踢脚线仅固定于墙面，不与浮筑层刚性连接 |

**标高推算**：

```
结构楼板标高（假设 ±0.000）
+ 弹性垫层：8mm
+ 砂浆浮筑层：50mm
+ 瓷砖面层：10mm
= 完成面标高：+0.068（增加 68mm）

需协调项：
- 门洞底标高须预留 ≥ 68mm + 门底缝隙
- 楼梯首步踏步高差需调整
- 厨卫完成面宜低于相邻房间 10-20mm（厨卫区域需单独处理）
```

### 方法论说明

本示例展示了 B2 验证协议的**完整五步骤执行流程**，核心方法论要点包括：
- **IC-10 标准推理**（Step 0）：正确识别住宅场景 → 调用 GB 55038-2025 → 选择 L'nT,w 评价量，避免引用已废止的 GB 50118-2010 住宅条文
- **评价量严格区分**：全程使用 L'nT,w（住宅现场值），未混用 Ln,w（实验室值）或 Rw（空气声），体现 FL-R-P0-1 和 FL-R-P1-3 的遵守
- **IC-08 计算调用**（Step 3）：展示 f₀ 共振频率计算、ΔLw 改善量估算、浮筑后 Ln,w 推算的完整 M5 模型过程
- **精度声明**：所有估算值均标注 ±4-6 dB 精度区间，未输出单一精确 dB 值（FL-R-P0-3）
- **声桥风险必检**：即使隔声估算值看似远低于限值，仍执行了声桥风险评估（FL-R-P1-6）
- **标高推算必检**：包含完整的标高叠加和协调项分析（FL-R-P1-7）

## 示例 2：酒店客房地面（架空 + 管线分离 + 高隔声要求）

### 场景描述

酒店改造项目，标准客房层需实现管线分离（水电管线在架空层内走管），同时满足酒店高要求级撞击声限值 Ln,w ≤ 55 dB（GB 50118-2010）。结构楼板为 120mm 钢筋混凝土。设计方提出采用架空地面方案（支撑脚 + 18mm 纤维水泥基层板 + PVC 面层），架空高度 120mm（含管线走管空间）。需验证架空地面是否可满足隔声要求，并协调多约束条件。

### 方法论运作过程

#### Step 0: 标准推理

**IC-10 调用**（SRE 场景推理引擎）：

```
请求参数：
  project_type: "hotel"（酒店）
  space_type: "guest_room"（客房）
  construction_type: "floor"
  performance_domains: ["impact_sound", "pipe_separation"]

IC-10 返回结果：
  适用标准集：
    - GB 50118-2010《民用建筑隔声设计规范》（L1 强制）— 酒店客房高要求级 Ln,w ≤ 55 dB
    - GB/T 50121-2005《建筑隔声评价标准》（L2 推荐）— 评价量定义
    - GB 55037-2022《建筑防火通用规范》（L1 强制）— 酒店楼地面防火要求
  强制评价量：Ln,w（实验室计权撞击声压级，T₀=1.0s）
  限值：≤ 55 dB（高要求级）
  注意：酒店为非住宅，不适用 GB 55038-2025，仍使用 GB 50118-2010
  注意：Ln,w（非住宅）与 L'nT,w（住宅）为不同评价量，不可混用（FL-R-P1-3）
```

#### Step 1: 输入解析

| 参数 | 值 | 来源 |
|------|-----|------|
| 建筑类型 | 酒店（改造项目） | 用户提供 |
| 空间类型 | 客房 | 用户提供 |
| 楼板基层 | 120mm 现浇钢筋混凝土 | 原设计图纸 |
| 裸板 Ln,w 基准 | 76-80 dB（取中值 78 dB） | reference.md A2 |
| 构造类型 | 架空地面 | 设计方指定 |
| 架空高度 | 120mm（支撑脚高度） | 设计方指定 |
| 基层板 | 18mm 纤维水泥板 | 设计方指定 |
| 基层板面密度 | ~25 kg/m² | 查表（纤维水泥板 ~1400 kg/m³） |
| 面层 | PVC 地板（~3mm） | 设计方指定 |
| 面层面密度 | ~5 kg/m² | 估算 |
| 浮筑层面密度 m' | 25 + 5 = 30 kg/m² | 计算 |
| 管线需求 | 水电管线架空层内走管 | 用户提供 |
| 标高约束 | 改造项目，净高影响需评估 | 用户提供 |

#### Step 2: 三原则审查

| 审查原则 | 审查结果 | 说明 |
|---------|---------|------|
| 评价量匹配 | ✓ 通过 | 酒店（非住宅） → 使用 Ln,w，未混用 L'nT,w 或 Rw（FL-R-P0-1 未触发） |
| 标准时效性 | ✓ 通过 | GB 50118-2010 非住宅部分现行有效，酒店客房高要求级 Ln,w ≤ 55 dB |
| 适用范围 | ⚠ 注意 | 架空地面的撞击声隔声评估需使用 M3 模型（MSM 弹簧-质量-弹簧），而非简单 M5 模型 |

#### Step 3: 计算验证（IC-08）

**关键判断：架空地面隔声评估模型选择**

架空地面属于 MSM（Mass-Spring-Mass）系统，两叶质量的归属为：**M1 = 结构楼板**（钢筋混凝土 120mm，288 kg/m²）— **空气弹簧 = 架空层**（120mm）— **M2 = 架空面板＋面层**（纤维水泥板 25 ＋ PVC 5 ＝ 30 kg/m²）。其隔声机理与浮筑地面（M5 单层弹簧-质量模型）不同，需使用 ACE M3 模型评估。

> **两叶归属纪律**：基层板与面层之间无弹性层（PVC 直铺于纤维水泥板上），二者刚性贴合，**只能合并为一叶**，不得把"基层板"与"面层"分别当作 M1、M2——那样等于把真正参与振动结构的质量（结构楼板 288 kg/m²）排除在模型之外：约化质量由 27.2 kg/m² 误算为 25×5/30＝4.17 kg/m²，f₀ 随 1/√m′ 被高估约 2.5 倍（√(27.2/4.17)≈2.55），并被误套进浮筑地面的 f₀ 分级表。

**ACE IC-08 调用过程**：

```
请求参数：
  base_slab: { type: "RC", thickness: 120mm, density: 288 kg/m² }
  model_type: "M3_MSM"（架空地面 MSM 模型）
  raised_floor: {
    support_height: 120mm,
    support_spacing: 600mm,
    base_board: { type: "fiber_cement", thickness: 18mm, density: 25 kg/m² }
  }
  finish_layer: { type: "PVC", thickness: 3mm, density: 5 kg/m² }
  evaluation_quantity: "Ln,w"
```

**MSM 模型简化估算**（ACE 降级策略备用）：

架空地面的 MSM 共振频率 f₀ 估算（空气弹簧刚度近似）：

```
架空层空气弹簧刚度：s_air ≈ ρ₀·c² / d
  其中 ρ₀ = 1.2 kg/m³（空气密度），c = 343 m/s（声速），d = 0.12 m（架空高度）
  s_air ≈ 1.2 × 343² / 0.12 ≈ 1.2 × 117649 / 0.12 ≈ 1,176,490 N/m³ ≈ 1.18 MN/m³

MSM 共振频率：f₀ ≈ (1/2π) × √(s_air × (M1+M2) / (M1×M2))
  M1 = 288 kg/m²（结构楼板），M2 = 25 + 5 = 30 kg/m²（架空面板＋面层，同叶合并）
  (M1+M2)/(M1×M2) = 318 / 8640 = 0.0368 m²/kg（约化质量 m′ ≈ 27.2 kg/m²）
  f₀ ≈ (1/2π) × √(1.18×10⁶ × 0.0368)
     ≈ (1/2π) × √(43,400)
     ≈ (1/2π) × 208
     ≈ 33 Hz
```

f₀ ≈ 33 Hz 低于撞击声单值评价频段（100-3150 Hz，含 50 Hz 第三倍频程）的下限，故共振放大区不落进评价主贡献频段——**仅作方向性判断，不作分级、不作改善量依据**。

> **本 MSM 近似的限制（不得越域使用）**：
> 1. 不得套用浮筑地面的 f₀ 分级表（"优/良好/一般/差"）——该分级表按 M5 浮筑构造的经验域建立，与 MSM 双叶系统不同源，代入即属越域使用；
> 2. 本近似只取架空层空气弹簧刚度，未计支撑点（600mm 间距）形成的点声桥、也未计面板弯曲刚度与空腔模态，实际共振频率与高频衰减均可能显著偏离；
> 3. 因此下方 ΔLw 与 Ln,w 系经验区间推算，据此得到的达标判断**只能是初步判断而非承诺性结论**，架空地面的撞击声改善量最终须以产品检测报告（实验室 Ln,w / ΔLw）或现场检测（L'nT,w）为准。

架空地面改善量估算（MSM 系统，高频衰减优于单质量系统）：

```
ΔLw(MSM) 在 f > f₀ 时衰减斜率约 -12 dB/oct（优于单质量系统的 -6 dB/oct）
估算 ΔLw ≈ 18-22 dB（架空 120mm + 18mm 纤维水泥板 + PVC 面层）

Ln,w(架空后) ≈ 78 - 20 ≈ 58 dB（取中值；78 dB 取 120mm 钢筋混凝土裸板 Ln,w 76-80 dB 区间中值）
区间估算：Ln,w ≈ 54-62 dB
```

**达标判断**：

```
Ln,w ≈ 54-62 dB vs 限值 ≤ 55 dB
结论：边界区域，乐观估算可达标（54-55 dB），保守估算可能不达标（60-62 dB）
建议：需要优化构造或增加隔声措施以确保达标
```

精度声明：ACE 专业估算，精度 ±4-6 dB。MSM 模型的不确定性高于 M5 模型，最终确认应以现场检测为准。

## 示例 4：地暖兼容浮筑地面（北方住宅）

### 场景描述

北方住宅项目，采用湿式地暖系统，同时需满足 GB 55038-2025 分户楼板撞击声要求（L'nT,w ≤ 65 dB）。设计方提出一体化构造：结构楼板 → 弹性垫（复合隔声垫，示例动刚度 s=10 MN/m³，厚 8mm）→ 地暖管（DN20，间距 200mm）→ 50mm 回填砂浆（含地暖管）→ 10mm 瓷砖面层。需评估浮筑隔声效果及地暖兼容性。

### 方法论运作过程

#### Step 0: 标准推理

**IC-10 调用**（SRE 场景推理引擎）：

```
请求参数：
  project_type: "residential"（北方住宅）
  space_type: "dwelling_unit_floor"（分户楼板）
  construction_type: "floor"
  performance_domains: ["impact_sound", "floor_heating"]

IC-10 返回结果：
  适用标准集：
    - GB 55038-2025《住宅项目规范》（L1 强制）— 分户楼板 L'nT,w ≤ 65 dB
    - GB/T 50121-2005《建筑隔声评价标准》（L2 推荐）— 评价量定义
    - JGJ 142-2012《辐射供暖供冷技术规程》— 地暖构造要求
  强制评价量：L'nT,w（现场标准化撞击声压级，T₀=0.5s）
  限值：≤ 65 dB
  附加要求：地暖兼容性评估（B5 功能适应性）
```

#### Step 1: 输入解析

| 参数 | 值 | 来源 |
|------|-----|------|
| 建筑类型 | 北方住宅（新建） | 用户提供 |
| 空间类型 | 分户楼板 | 用户提供 |
| 楼板基层 | 120mm 现浇钢筋混凝土 | 设计图纸 |

| 弹性垫厚度 | 8mm | 用户提供 |
| 地暖系统 | 湿式地暖，DN20 管，间距 200mm | 设计方指定 |
| 回填砂浆 | 50mm（含地暖管） | 设计方指定 |
| 砂浆面密度 | ~85 kg/m² | 计算（50mm × 1700 kg/m³） |
| 面层 | 10mm 瓷砖 | 设计方指定 |
| 瓷砖面密度 | ~22 kg/m² | 查表 |

#### Step 2: 三原则审查

| 审查原则 | 审查结果 | 说明 |
|---------|---------|------|
| 评价量匹配 | ✓ 通过 | 住宅分户楼板 → 使用 L'nT,w；L'nT,w 不提供数值估算（两量间无换算式），达标以现场检测判定，已在 Step 3 披露 |
| 标准时效性 | ✓ 通过 | GB 55038-2025 现行有效 |
| 适用范围 | ⚠ 注意 | 地暖兼容性需专项评估（B5），弹性垫不应阻断地暖热传导路径 |

#### Step 3: 计算验证（IC-08）

**ACE IC-08 调用过程**：

```
请求参数：
  base_slab: { type: "RC", thickness: 120mm, density: 288 kg/m² }
  resilient_layer: { material: "composite_pad", s: 10e6 N/m³, thickness: 8mm }
  floating_layer: { type: "mortar_with_heating", thickness: 50mm, density: 85 kg/m² }
  finish_layer: { type: "ceramic_tile", thickness: 10mm, density: 22 kg/m² }
  total_mass_m_prime: 95 kg/m²
  evaluation_quantity: "Ln,w"
  special_condition: "floor_heating_compatible"
```

**M5 模型手算验证**：

**① 共振频率 f₀ 计算**：

```
f₀ = (1/2π) × √(s / m')
   = (1/2π) × √(10×10⁶ / 95)
   = (1/2π) × √(105263)
   = (1/2π) × 324.4
   ≈ 51.6 Hz
```

f₀ ≈ 52 Hz → **优秀**（f₀ < 80 Hz，全频段有效改善）

**② 改善量 ΔLw 估算**：

```
ΔLw ≈ 18·log₁₀(m') - 10·log₁₀(s) + C
    = 18·log₁₀(95) - 10·log₁₀(10) + 10
    = 18 × 1.978 - 10 × 1.000 + 10
    = 35.6 - 10.0 + 10
    ≈ 35.6 dB
```

**③ 浮筑后撞击声压级估算**：

```
Ln,w(裸板) ≈ 78 dB
Ln,w(浮筑) ≈ 78 - 35.6 ≈ 42.4 dB
区间估算：Ln,w ≈ 40-44 dB
L'nT,w 现场估算：不提供数值（实验室 Ln,w 与现场 L'nT,w 之间无换算式，区间加宽亦无依据）
```

**④ 达标判断**：

```
L'nT,w 无数值出口，不作与限值的数值比较
结论：不作达标判定——达标须以现场 L'nT,w 检测判定
```

精度声明：ACE 专业估算，精度 ±4-6 dB，最终确认应以现场 L'nT,w 检测为准。

- 浮筑层面密度 m'=95 kg/m²（含 50mm 回填砂浆和 10mm 瓷砖）
- 地暖供水温度 ≤ 50°C（低温热水系统），回填砂浆工作温度约 35-45°C
- ACE M5 模型修正常数 C=10

**专业边界声明**

本方案为装配式楼地面专业估算，不替代以下专业工作：
- 结构承载力计算（应由结构工程师完成）
- 现场隔声检测（应由有 CMA/CNAS 资质的检测机构执行）
- **地暖热工计算和管布置设计**（应由暖通工程师完成，FL-R-P0-4）
- 回填砂浆配合比设计（应由材料/结构工程师确认）
- 消防设计审查（应由具有相应资质的消防设计审查机构负责）

### 方法论说明

本示例展示了**地暖兼容性评估（B5）**与隔声验证的交叉场景，核心方法论要点包括：
- **地暖兼容性五维度评估**：弹性垫耐温性、热传导影响、弹性垫位置优化、温度缝设置、地暖功率补偿
- **专业边界明确标注**：地暖热工计算明确转介暖通工程师（FL-R-P0-4），FL 仅评估兼容性方向
- **构造顺序分析**：弹性垫在地暖管下方，分析其对热传导方向的影响（向下阻隔有利），而非简单判断"有影响/无影响"
- **隔声与地暖协同**：浮筑隔声构造与地暖回填砂浆一体化，总厚度与非地暖方案一致（68mm），标高协调无额外困难
- **施工控制要点**：回填砂浆养护期间禁止启暖、首次启暖缓慢升温等施工控制点，体现 B4 施工控制原则

## 示例 5：极端隔声需求（录音棚 / 琴房地面）

### 场景描述

专业录音棚项目，要求地面撞击声 Ln,w ≤ 45 dB，远超常规住宅（65 dB）和酒店高要求级（55 dB）的限值。结构楼板为 150mm 钢筋混凝土（裸板 Ln,w ≈ 74-78 dB，取中值 76 dB）。设计方提出采用复合构造（浮筑 + 架空双层系统）以达到极端隔声要求。需评估可行性并给出风险提示。

### 方法论运作过程

#### Step 0: 标准推理

**IC-10 调用**（SRE 场景推理引擎）：

```
请求参数：
  project_type: "studio"（专业录音棚）
  space_type: "recording_studio"（录音棚）
  construction_type: "floor"
  performance_domains: ["impact_sound"]

IC-10 返回结果：
  适用标准集：
    - 无专项强制性国标（录音棚撞击声限值通常由业主或声学顾问指定）
    - GB 50118-2010《民用建筑隔声设计规范》可参考（但无录音棚专项条文）
    - GB/T 50121-2005《建筑隔声评价标准》（L2 推荐）— 评价量定义
    - GB/T 19889.7-2022（L2 推荐）— 现场检测方法
  评价量：Ln,w（实验室计权撞击声压级）
  限值：≤ 45 dB（业主指定，超出常规标准限值范围）
  注意：此限值远超 GB 50118-2010 中最严格的限值（55 dB），属于专项声学设计范畴
```

**FL 能力边界判断**：

```
Ln,w ≤ 45 dB 要求分析：
  裸板 Ln,w ≈ 76 dB（150mm 钢筋混凝土）
  需要改善量：ΔLw ≥ 76 - 45 = 31 dB
  考虑精度 ±4-6 dB，实际需 ΔLw ≥ 37 dB 以确保达标
  常规浮筑地面改善量：18-25 dB → 不满足
  常规架空地面改善量：18-22 dB → 不满足
  复合构造（浮筑+架空）：理论可达 30-40 dB → 边界区域
  
结论：超出 FL 常规能力范围，建议专项声学设计
触发红线：FL-R-P0-4（超出专业边界）+ FL-R-P0-3（不确定性极高）
```

#### Step 2: 三原则审查

#### Step 3: 计算验证（IC-08）

**复合构造初步估算**（仅供方向性参考，不替代专项声学设计）：

拟定复合构造：

```
层次（从上至下）：
1. 面层：实木地板（15mm，~10 kg/m²）
2. 架空基层板：18mm 纤维水泥板（~25 kg/m²）
3. 架空层：80mm（支撑脚，内填吸声材料）
4. 浮筑层弹性垫：复合隔声垫（s=10 MN/m³，8mm）（示例数据）
5. 浮筑砂浆层：40mm（~68 kg/m²）
6. 第二层弹性垫：复合隔声垫（s=10 MN/m³，8mm）（示例数据）
7. 150mm 钢筋混凝土楼板（基层）
```

**第一级隔声（上层浮筑：弹性垫 6 + 砂浆层 5 + 架空板 2 + 面层 1）**：

```
m'₁ = 68 + 25 + 10 = 103 kg/m²
s₁ = 10×10⁶ N/m³

f₀₁ = (1/2π) × √(10×10⁶ / 103) ≈ 49.6 Hz → 优秀

ΔLw₁ ≈ 18·log₁₀(103) - 10·log₁₀(10) + 10
      = 18 × 2.013 - 10 × 1.000 + 10
      = 36.2 - 10.0 + 10
      ≈ 36.2 dB
```

**第二级隔声（架空层：架空板 2 与浮筑砂浆 5 之间的空气弹簧）**：

```
架空层空气弹簧：s_air ≈ ρ₀·c² / d = 1.2 × 343² / 0.08 ≈ 1,764,735 N/m³ ≈ 1.76 MN/m³

MSM 共振频率（M1=68 kg/m² 浮筑层，M2=35 kg/m² 架空板+面层）：
f₀₂ ≈ (1/2π) × √(1.76×10⁶ × 103 / (68×35))
    ≈ (1/2π) × √(76,263)
    ≈ (1/2π) × 276.2
    ≈ 43.9 Hz（第二级属 MSM 双叶系统，不适用浮筑地面 f₀ 分级表，见本件「本 MSM 近似的限制」第 1 条）

ΔLw₂ ≈ 12-18 dB（MSM 系统第二级隔声，取决于频率和阻尼）
```

**复合构造总改善量估算**：

```
ΔLw(total) ≈ ΔLw₁ + ΔLw₂（理想叠加，实际因耦合效应会有折减）
           ≈ 36.2 + 15（取中值） - 5（耦合折减）
           ≈ 46 dB（越域：超出本件「复合构造（浮筑+架空）：理论可达 30-40 dB」经验域上界 6 dB，属理想叠加外推）

Ln,w(复合) ≈ 76 - 46 ≈ 30 dB（理想估算）
考虑精度和实际因素：Ln,w ≈ 30-40 dB（乐观），Ln,w ≈ 40-50 dB（保守）
```

**关键判断**：

```
乐观估算 Ln,w ≈ 30-40 dB → 可满足 ≤ 45 dB
保守估算 Ln,w ≈ 40-50 dB → 边界区域

结论：复合构造理论上有可能达到 Ln,w ≤ 45 dB，但：
  1. 估算精度极低（复合构造超出 M5 单模型范围，多级系统耦合效应难以精确估算）
  2. 实际效果高度依赖施工质量（声桥控制、边缝密封、多层弹性垫对齐等）
  3. 必须进行专项声学设计和现场检测验证
  
触发：FL-R-P0-4（建议转介专业声学顾问）
触发：FL-R-P0-3（极高不确定性，必须标注）
```

### 方法论说明

本示例展示了**无隔声需求的快装地面场景**下 B2 验证协议的执行，核心方法论要点包括：
- **隔声功能剥离**：当业主明确声明隔声由结构层满足时，FL 正确识别快装面层不承担隔声功能，不强制要求隔声计算验证，但标注了隔声限制（FL-R-P0-1 不混淆评价量的延伸应用）
- **临界值处理**：基层平整度 3mm/2m 恰好在 SPC 锁扣的临界值，FL 给出"局部修补后铺设"的务实建议，而非简单判定合格/不合格
- **快装场景的简化验证**：Step 3 ACE 调用仍执行（提供 ΔLw 估算），但 Step 4 核验清单中隔声项标记为"—"（不适用），体现灵活的流程适配
- **成本与工期优势体现**：快装方案的核心价值（50-120 元/m²、0.5-1 天施工周期）在输出中清晰呈现，与浮筑/架空方案形成对比参照
