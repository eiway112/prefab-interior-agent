## 示例 1：B1 管线分离策略制定（住宅项目）

**用户输入**：住宅项目，墙地顶都想做管线分离，怎么规划强弱电、给排水、暖通？

**输入分类**：C 类对比/策略制定。

**应答示例**：

```markdown
## 需求概述
- 项目类型：住宅
- 系统范围：强电、弱电、给水、排水、暖通支管
- 核心诉求：实现结构-管线-装饰三层分离，便于检修更换

## 管线分离策略

| 系统 | 推荐布置区域 | 空腔需求 | 判定 | 数据来源 |
|------|------------|---------|------|---------|
| 强电 | 墙面空腔、吊顶 | 墙面≥50mm，吊顶≥150mm | ✅ 可行 | S2：本合集工程经验控制值（承载标准未经核，见台账 PL-127） |
| 弱电 | 墙面空腔、吊顶 | 与强电平行间距≥300mm | ✅ 可行 | S2：本合集工程经验控制值（承载标准未经核，见台账 PL-123） |
| 给水 | 墙面空腔、吊顶 | 管外径+20mm | ✅ 可行 | S1：GB 50242-2002 |
| 排水 | 厨卫管井、架空地面 | 降板 300mm 或架空 200mm | ✅ 可行 | S1：GB 50242-2002 |
| 地暖 | 架空地面 | 架空高度≥管外径+20mm | ✅ 可行 | S1：JGJ 142-2012 |
| 空调冷媒管 | 吊顶空腔、局部墙面 | ≥150mm | ✅ 可行 | S2：行业通用做法 |

## 关键控制点
- 厨卫区域管线宜避开防水层；确需穿越楼板时应设防水套管并密封（S1：GB 55030-2022 第4.6.6条第3款，其逐字对象为「穿过楼板的防水套管」，2026-09-25 官方出版物核验；该值不推广到仅穿防水层而未穿楼板的部位）。「管线不得穿越防水层」**不作为规范禁止性条文引用**：现行已核验条文中无该禁令，约束以套管＋密封接口做法表达（见同件 SKILL.md §2.1）
- 强弱电平行间距≥300mm，交叉≥100mm（S2：本合集工程经验控制值，具体以设计文件为准；承载标准未经核，见台账 PL-123）
- 吊顶内设备必须独立吊挂，不得搁置于龙骨
- 检修口尺寸按对象分档（分档单源见 reference.md §4.1）：给排水阀门／喷淋阀门处≥400×400mm，电气接线盒与管道接头／三通处≥300×300mm，设备区≥600×600mm；各档均系本合集经验数据（S2），承载标准未经核见台账 PL-201

## 风险提示
- 具体管径、负荷计算须由注册设备工程师完成
- 架空地面荷载须结构复核
```

## 示例 2：B2 冲突检查（吊顶内风管与桥架标高冲突）

**用户输入**：吊顶空腔净高 250mm，里面要走 200×150mm 风管和 100×50mm 桥架，会不会冲突？

**输入分类**：A 类方案验证。

**应答示例**：

```markdown
## B2 冲突检查报告

### 1. 输入信息
- 吊顶空腔净高：250mm
- 风管尺寸：200mm（高）×150mm（宽）
- 桥架尺寸：100mm（高）×50mm（宽）
- 其他管线：暂无

### 2. 逐项验证

| 检查项 | 输入值 | 规范/要求 | 结论 | 备注 |
|--------|--------|----------|------|------|
| 风管占用高度 | 200mm | 须预留≥50mm 安装/保温空间 | ⚠️ CONDITIONAL | 实际占用约 200~250mm |
| 桥架占用高度 | 100mm | 须预留≥20mm 安装空间 | ✅ 满足 | 单独满足 |
| 叠加总高 | 约 300~350mm（含间距） | ≤250mm | ❌ FAIL | 超出吊顶空腔净高 |
| 检修空间 | 未说明 | 设备区≥600×600mm | ❓ 待确认 | 须补充检修口方案 |

### 3. 验证结论
**FAIL**

整改建议：
1. 改变风管路路由，或改用扁平风管／优化管段截面（吊顶侧判序第 1—2 步「管线改路由→截面优化」，见 prefab-ceiling-system/reference.md「B3.2 最低标高核算流程」）
2. 调整桥架路径，避免与风管同一路由（同属「改路由」一支，仍优先于动净高）
3. 上述两支均不可行时，才评估提高吊顶空腔净高至≥350mm——该支以牺牲室内净高换空腔，须先确认室内净高余量并经设计侧确认，不得列为首选（本示例原把它列第 1 条，与吊顶侧判序互斥，随批取齐）
4. 补充检修口位置与尺寸（与上述三支并行，不因重排而撤）

### 4. 风险提示
- 吊顶设备荷载须独立吊挂
- 风管与桥架交叉时须保证最小净距
```

## 示例 3：P0 红线触发处理（燃气管暗埋）

**用户输入**：厨房燃气管想暗埋在橱柜后面的墙里，美观一些。

**应答示例**：

```markdown
[MI-R-P0-3 触发] 严禁燃气管暗埋于密闭空腔

燃气管严禁暗埋于不通风的密闭空腔或墙体内部（GB 50028-2006）。暗埋会导致泄漏燃气聚集，存在爆炸风险。

**因此，该方案不可实施。**

**合规做法**：
- 燃气管明装于厨房通风处
- 或敷设于专用通风管井内
- 燃气设计须由具备燃气设计资质的单位完成

**本技能可协助内容**：
- 橱柜布局与燃气设备预留尺寸协调
- 厨房其他机电管线综合排布
- 燃气路由与相邻部品接口提示
```

## 示例 4：P0 红线触发处理（管线穿越防水层无套管）

**用户输入**：卫生间给水管直接从防水层穿过去接花洒，可以吗？

**应答示例**：

```markdown
[MI-R-P0-4 触发] 严禁管线无套管穿越防水层

管线穿越厨卫防水层时必须设置套管，并做密封处理，否则将破坏防水层，造成渗漏隐患。穿楼板的防水套管应高出装饰层完成面且高度不应小于 20mm（S1：GB 55030-2022 第4.6.6条第3款，2026-09-25 官方出版物核验），套管与管道间的密封做法系本合集接口控制要求（S3）。

**因此，该做法不可直接实施。**

**必须完成的事项**：
- 防水施工前完成套管预埋
- 套管与管线间填充密封材料
- 防水附加层覆盖套管根部
- 闭水试验合格后方可封板

**本技能可协助内容**：
- 管线分离路径规划
- 厨卫设备接口点位协调
- 隐蔽验收节点提示
```

## 示例 5：跨技能路由（吊顶内管线与吊顶系统协同）

**用户输入**：吊顶净高只有 220mm，里面要走新风管和灯带，需要吊顶系统配合吗？

**应答示例**：

```markdown
本技能负责管线综合与路径规划，吊顶构造、检修口、龙骨荷载须由吊顶系统专项技能确认。

**建议下一步**：
- 吊顶构造与检修口设计 → 调用 **prefab-ceiling-system**
- 新风管管径/风量复核 → 委托暖通工程师
- 灯带电气管线敷设 → 继续由本技能处理

**本技能可协助内容**：
- 新风管与灯带路径优化
- 标高冲突识别
- 吊顶内管线综合优先级排布
```

## 示例 6：数据分级标注示例

**用户输入**：强弱电线管同槽敷设，间距 50mm 可以吗？

**应答示例**：

```markdown
| 项目 | 说明 | 数据来源 |
|------|------|---------|
| 本合集控制值 | 强弱电平行敷设间距≥300mm，交叉≥100mm | S2：本合集工程经验控制值（GB 50303-2015 第12.2.3条经 2026-10-02 逐字面核验不载本值；承载标准未经核，见台账 PL-123） |
| 当前输入 | 平行间距 50mm | 用户提供 |
| 结论 | 不满足本合集最小间距控制值，存在干扰与安全隐患 | S2：由上表本合集控制值推定（**不得表述为满足／不满足国家规范条文**——该值的承载标准未经核，见台账 PL-123） |
| 建议 | 强弱电分槽敷设，或采用金属屏蔽管并加大间距 | S2：行业通用做法 |

> 具体项目应以设计文件和现行标准原文为准；涉及电气安全须由电气工程师确认。
```
