# 装配式装修规范标准复核 — 使用示例

## 示例一：隔墙性能指标全面复核

**场景**：用户要求"请基于规范标准复核隔墙技能中'隔墙性能指标要求'表格中的所有数据，必须要准确、表述严谨！"

**执行流程**：

### 步骤1：读取技能文件

读取隔墙技能SKILL.md，识别"隔墙性能指标要求"表格中的所有数据项：
- 住宅分户墙：DnT,w+C≥50/48 dB，耐火≥2.00h，依据GB 55038-2025
- 酒店客房隔墙：Rw+C≥45~50 dB，耐火≥1.00h~2.00h，依据JGJ 62
- 医院病房隔墙：Rw+C≥40~45 dB，依据GB 51039
- 等等

### 步骤2：搜索核验标准

```
搜索关键词：
- "GB 55038-2025 住宅项目规范 隔声"
- "GB 50118 民用建筑隔声设计规范 分户墙"
- "JGJ 62 旅馆建筑设计规范 隔声"
- "GB 51039 综合医院建筑设计规范 隔声"
```

### 步骤3：对比分析

**发现的问题**：
1. GB 55038-2024年份错误，应为GB 55038-2025
2. 办公隔声依据标准引用GB 50189，应为GB 50118
3. 学校隔声依据引用JGJ 36混乱，应为GB 50118+GB 55037-2022

### 步骤4：执行修正

使用Edit工具逐一修正，每次修正后验证结果。

### 步骤5：生成报告

```markdown
# 隔墙性能指标规范标准复核报告

## 复核日期
2026-05-13

## 复核范围
- 复核文件：SKILL.md中"隔墙性能指标要求"表格
- 重点内容：隔声指标、耐火极限、依据标准

## 发现并修正的问题

### 问题1：标准年份错误
- **位置**：住宅分户墙行
- **原内容**：GB 55038-2024
- **问题描述**：标准年份错误（GB 55038-2024已不存在，正确年份为2025）
- **修正后**：GB 55038-2025
- **依据**：住建部公告，2025年5月1日实施

### 问题2：依据标准错配
- **位置**：办公隔声行
- **原内容**：GB 50189
- **问题描述**：GB 50189为公共建筑节能标准，非隔声规范
- **修正后**：GB 50118
- **依据**：GB 50118《民用建筑隔声设计规范》

## 结论
本次复核共发现3处问题（本示例展示其中2处），已全部修正。
```

## 示例二：边界符号专项复核

**场景**：用户要求"关于隔墙技能中'隔墙性能指标'中'≥'和'＞'的边界需要确认无误"

**执行流程**：

### 步骤1：提取所有边界符号

从技能文件中提取所有使用"≥"和">"的位置：
- DnT,w+C≥50 dB
- DnT,w+C≥48 dB
- Rw+Ctr≥50 dB
- Rw+Ctr>55 dB
- 耐火极限≥2.00h
- 等等

### 步骤2：查阅标准原文

搜索每个指标对应的标准原文，确认原文表述：
- GB 55038-2025第6.1.2条："不应小于"→≥
- GB 50118："大于"→>

### 步骤3：核验结果

**发现**：
- 所有"≥"均对应标准原文"不应小于"，正确
- 唯一">"用于医院病房与噪声房间隔墙（Rw+Ctr>55 dB），对应GB 50118原文"大于"，正确

**结论**：边界符号使用准确，无需修正。

## 示例三：多技能一致性检查

**场景**：用户要求"再检查一遍两个技能的一致性"

**执行流程**：

### 步骤1：读取全部文件

读取主技能（prefab-interior-materials-expert）和子技能（prefab-partition-wall-solution）的全部6个文件。

### 步骤2：逐项对比

| 检查项 | 主技能 | 子技能 | 结果 |
|-------|-------|-------|------|
| GB 55038引用 | GB 55038（SKILL.md）/ GB 55038-2025（reference.md） | GB 55038-2025 | ✅ 一致 |
| 隔声指标体系 | 未涉及具体数值 | DnT,w+C/Rw+C/Rw+Ctr | ✅ 分工合理 |
| 建筑类型覆盖 | 住宅/酒店/医院/办公等 | 住宅/酒店/医院/办公/学校/长租公寓 | ✅ 一致 |
| 免责提示 | 标准文本 | 标准文本 | ✅ 一致 |

### 步骤3：发现不一致

**示例一不一致**：
- 子技能examples.md示例一使用"Rw+Ctr≥45 dB"
- 子技能SKILL.md表格使用"DnT,w+C≥48 dB"
- 修正：将示例一统一为DnT,w+C≥48 dB

### 步骤4：修正并确认

执行修正后再次检查，确认所有维度一致。

## 示例四：新技能发布前复核

**场景**：用户创建了新技能，要求"发布前复核一遍所有技术指标"

**执行流程**：

### 步骤1：建立复核清单

```
复核清单：
- [ ] 所有标准编号及年份准确性

- [ ] 所有标准引用条款号正确性
- [ ] 术语使用规范性
- [ ] 边界符号（≥/＞/≤/＜）准确性
- [ ] 数据来源标注清晰性
- [ ] 示例与主表格一致性
```

### 步骤2：逐项核验

按清单逐项搜索核验，记录结果。

输出包含所有核验项的详细报告，标注"通过"或"发现问题"。

### 步骤4：修正与确认

对发现的问题执行修正，修正后再次核验确认。
