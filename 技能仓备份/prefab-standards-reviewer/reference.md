## 二、隔声评价指标体系详解

### 2.1 实验室指标

**Rw+C（计权隔声量+粉红噪声频谱修正量）**
- 测试方法：GB/T 45305.2-2025（实验室测量，2026-02-01实施）
- 适用场景：大多数室内隔墙场景
  - 住宅室内隔墙
  - 酒店客房隔墙
  - 医院病房隔墙
  - 办公室隔墙
  - 教室隔墙

**Rw+Ctr（计权隔声量+交通噪声频谱修正量）**
- 测试方法：GB/T 45305.2-2025（实验室测量，2026-02-01实施）
- 适用场景：特定场所
  - 住宅分户墙（GB 50118-2010高要求标准）
  - 住宅临交通干线侧隔墙
  - 医院病房与产生噪声房间之间的隔墙

### 2.2 现场指标

**DnT,w+C（计权标准化声压级差+粉红噪声频谱修正量）**
- 测试方法：GB/T 19889.1-2026（现场测量，2026-08-01实施）
- 适用场景：GB 55038-2025规定的住宅分户墙现场验收检测
- 与实验室指标的区别：
  - 测试环境不同：现场 vs 实验室
  - 包含侧向传声影响
  - 数值通常低于实验室指标
  - 两者不可直接比较

### 2.3 标准原文关键条款

**GB 55038-2025第6.1.2条（强制性条文）**
- 卧室分户墙：DnT,w+C≥50 dB
- 其他分户墙：DnT,w+C≥48 dB

**GB 50118-2010相关条款**

> **住宅面废止注记**：GB 50118-2010 住宅相关强条第 4.2.1、4.2.2、4.2.5 条已由 GB 55038-2025 接管（住建部公告 2025 年第 39 号），本合集未提取该三条条文内容 ⇒ 下列住宅面两行原列值按 GB 50118-2010 引用**属零凭据，不得作住宅分户墙限值**。住宅面真值源＝**GB 55038-2025 第 6.1.2 条**：卧室分户墙 DnT,w+C≥50 dB、其他分户墙 DnT,w+C≥48 dB（现场量；该条不设 R_w 限值）。**S3**（住宅面两行原列值未经条文级核验且所挂强条已废止，仅作历史形制对照）

- 住宅分户墙（高要求）：~~Rw+C＞50 dB~~ —— **已废止口径，不得作限值**；按 GB 55038-2025 第 6.1.2 条判（DnT,w+C）
- 住宅分隔非住宅用途：~~Rw+C≥45 dB~~ —— **已废止口径，不得作限值**（本合集无该行现行条文级承接凭据）
- 酒店客房之间：Rw+C≥45~50 dB
- 医院病房之间：Rw+C≥40~45 dB
- 医院病房与噪声房间：Rw+Ctr>55 dB

## 三、边界符号对照表

| 标准原文表述 | 数学符号 | 示例 |
|-------------|---------|------|
| 不应小于 | ≥ | 耐火极限不应小于2.00h → ≥2.00h |
| 不应大于 | ≤ | 平整度不应大于3mm → ≤3mm |
| 大于 | > | 错位大于200mm → >200mm |
| 小于 | < | （较少使用） |
| 不应低于 | ≥ | 燃烧性能不应低于B1级 → ≥B1级 |
| 不应高于 | ≤ | （较少使用） |

## 四、数据来源分类

| 数据类型 | 定义 | 标注要求 | 示例 |
|---------|------|---------|------|
| 标准数据 | 来源于国家/行业/地方标准 | 标注标准编号、条款号 | GB 55038-2025第6.1.2条 |
| 产品数据 | 来源于产品标准或检测报告 | 标注"厂家技术资料"或"第三方检测报告" | 厂家检测报告 |
| 市场数据 | 价格、占有率等非标准数据 | 标注"市场参考数据"并注明时效 | 市场参考数据（2024-2025年） |
| 经验数据 | 工程经验值、推荐做法 | 标注"行业经验建议"或"工程惯例" | 行业经验建议值 |

## 五、常见问题案例库

### 案例1：标准年份错误

**问题**：引用GB 55038-2024

**修正**：GB 55038-2025（2025年5月1日实施）

**核验方法**：搜索"GB 55038 最新版本"确认

### 案例2：依据标准错配

**问题**：办公建筑隔声依据标准引用GB 50189（节能标准）

**修正**：应引用GB 50118（隔声规范）

**核验方法**：确认标准名称与问题领域匹配

### 案例3：指标体系混用

**问题**：住宅分户墙引用GB 55038-2025但使用Rw+Ctr指标

**修正**：GB 55038-2025使用DnT,w+C现场指标

**核验方法**：确认标准使用的指标体系类型

### 案例4：边界符号错误

**问题**：医院病房隔墙使用Rw+Ctr≥55 dB

**修正**：GB 50118原文为"大于"，应使用Rw+Ctr>55 dB

**核验方法**：查阅标准原文确认"大于/不应小于"等表述

## 六、多技能一致性检查清单

| 检查项 | 检查内容 | 通过标准 |
|-------|---------|---------|
| 标准引用 | 同一标准在多个技能中的引用是否一致 | 标准编号、年份、名称一致 |
| 指标体系 | 隔声、耐火等指标体系是否统一 | 指标类型、符号使用一致 |
| 术语使用 | 专业术语的使用是否统一 | 术语定义、缩略语一致 |
| 符号使用 | ≥、>、≤、<等符号使用是否准确 | 与标准原文对应 |
| 免责提示 | 标准免责提示文本是否一致 | 文本内容完全一致 |
| 示例内容 | 示例中的指标与主表格是否一致 | 数值、指标类型一致 |
