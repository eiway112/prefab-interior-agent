## 示例 1：住宅楼板隔声吊顶（IC-09 贡献量估算全链路）

### 场景描述

用户：我家楼上说话声很清楚，想做个隔音吊顶解决。楼板是 120mm 钢筋混凝土，吊顶空腔大概能做到 200mm。装了吊顶能不能达标？

### 方法论运作过程

#### Step 0: 标准推理（IC-10 → SRE）

请求参数：{项目类型: 住宅, 空间类型: 户内吊顶（隔声需求）, 项目所在地: 全国（未提供，按 IC-10 默认不筛选地方标准）, 构造体系: "吊顶", 性能需求: [隔声]}

SRE 返回（吊顶域激活行）：

- 激活领域：acoustic(贡献)、fire、acceptance、prefab
- 适用标准集：GB 55037-2022 / GB 50222-2017（防火，GB 8624-2012 燃烧性能分级处过渡期〔CL-R-P1-4〕）、GB 50210-2018（验收）、JGJ/T 491-2021（装配式）、GB 55038-2025（声学贡献场景宿主构件达标归口）
- 声学口径：吊顶为贡献量非独立判据；达标归属宿主构件标准 GB 55038-2025（住宅分户楼板）；估算经 IC-09（ACE）

#### Step 1: 输入解析

| 输入项 | 值 | 状态 |
|--------|-----|------|
| 宿主构件 | 120mm 钢筋混凝土楼板 | 已知 |
| 空腔高度 | 约 200mm | 已知 |
| 噪声类型 | 楼上说话声（空气声） | 已知 |
| 吊挂条件 | 未确认 | 需追问 |
| 面板偏好 | 未提供 | 需追问 |

追问：吊挂条件如何（吊杆类型、楼板可承重状况）？是否需要保留尽量多的净高？楼板上方是否有浮筑构造或其他治理措施？（源头治理优先核查；若伴随撞击声诉求见 A1.4，浮筑构造归 FL 域）

#### Step 2: 三原则审查

- 场景匹配：住宅户内吊顶 + 隔声需求 → 轻钢龙骨板材路线（隔声贡献主力路线）
- 标准时效性：GB 55038-2025 现行有效（2025-05-01 实施）；GB 8624-2012 处于过渡期（2025 版 2027-01-01 实施，CL-R-P1-4 标注）
- 声学贡献量边界：**用户问"能不能达标"——触发 CL-R-P2-3 口径澄清**：吊顶输出为贡献量估算，达标归属宿主构件（楼板），不得直接回答"达标/不达标"

#### Step 3: 计算与核验（IC-09 → ACE）

参数组装（最小必传集，reference.md §四 B5.2）：

```
发起方：CL
评价量：Rw+C（宿主构件为住宅分户楼板，空气声路径）
构造类型：隔声吊顶
面板层：双层纸面石膏板 2×12mm（深化建议，产品参数以厂家报告为准〔S2〕）
空腔层：深度 200mm，填充岩棉（填充率按深化设计）
吊挂系统：弹性吊挂（减振吊钩）（深化建议，待用户确认吊挂条件后核实）
收口密封：周边弹性密封胶收口（深化节点）
```

ACE 返回（演示估算值）：本次 ACE 返回的是**构造绝对量**（评价量 Rw+C，估算精度 ±4-6 dB），其具体区间须按当次调用取得并单列；本行原写的 5-10 dB **不是该绝对量**，而是**经验提升量（贡献量 Δ）**的演示给值（取本件 A1.2 经验区间 5-15 dB 内的 S3 经验值，**非本次计算结果**、不随 ACE 精度给出）——绝对量与增量两套量纲不得互推、不得夹取，见本件 reference.md「B5.3 输出解读规则」〔订正 2026-09-22〕；本行原把该枚经验增量挂「Rw+C 口径」并把 ACE 的 ±4-6 dB 写成它的精度，两头均属该订正所禁的口径混用，随批改标。吻合效应风险：低（双层板错缝安装前提下）；密封评估：充分（假设周边弹性密封胶收口到位；实际施工不符时须重新评估）。

#### Step 4: N 维度核验

| 维度 | 结果 | 说明 |
|------|------|------|
| D1 防火 | ✓ | 住宅吊顶面板 ≥B1 级（GB 55037-2022 / GB 50222-2017 表 5.1.1 序号 17〔S1-，2026-08-08 已核验〕） |
| D2 结构荷载 | 转介 | 双层石膏板+岩棉+龙骨自重及吊杆承载力由结构计算确认（CL-R-P0-1） |
| D3 机电协同 | — | 用户未提机电需求；如空腔内走管线，按 B3 核算标高 |
| D4 检修口 | ✓ | 封闭吊顶按阀门/接头位置预留检修口（B3.3） |
| D5 标高 | ⚠️ | 空腔 200mm + 龙骨面板厚度，净高损失约 230-250mm，需用户确认 |
| D6 隔声贡献 | ✓ | IC-09 估算完成，贡献量口径输出（CL-R-P2-3） |
| D7 环保 | ✓ | 石膏板为无机材料甲醛风险低；如涉及木质龙骨/胶黏剂/人造板复合板按 GB 18580-2025 核验（A4.1/A4.3） |
| D8 平整度 | ✓ | 板材吊顶 ≤3mm/2m（GB 50210-2018 表 7.3.10 石膏板允许偏差〔S1，2026-08-08 已核验〕） |

#### Step 5: 输出组装

### 标准输出

```
【需求概述】
住宅户内，楼上说话声（空气声）困扰，拟设隔音吊顶；宿主构件 120mm 钢筋混凝土楼板，
空腔约 200mm。

【适用标准】（SRE 推理结果）
| 标准编号 | 标准名称 | 适用内容 |
|---------|---------|---------|
| GB 55038-2025 | 住宅项目规范 | 宿主构件（分户楼板）达标归属 |
| GB 55037-2022 / GB 50222-2017 | 防火通用规范 / 内部装修防火规范 | 面板燃烧性能 |
| GB 50210-2018 | 建筑装饰装修工程质量验收标准 | 验收偏差 |

【验证记录】
Step 0 SRE 推理 ✓（acoustic(贡献)/fire/acceptance/prefab）；Step 2 三原则审查 ✓
（贡献量边界已澄清）；D1-D8 核验见上表。

【系统选型】
| 维度 | 选型 | 依据 |
|------|------|------|
| 龙骨体系 | C 型轻钢龙骨 | 隔声贡献主力路线（B1） |
| 面板类型 | 双层纸面石膏板（≥B1 级） | 面密度+双层错缝（A1.2） |
| 空腔 | 200mm 填岩棉 | 用户条件 |
| 吊挂 | 弹性吊挂（减振吊钩） | 减少声桥（A1.2 短板控制） |

【隔声贡献估算】
- 宿主构件：120mm 钢筋混凝土楼板
- 吊顶贡献估算：**经验提升量（贡献量 Δ）**约 5-10 dB（取本件 A1.2 经验区间 5-15 dB 内的演示给值，S3 经验值，**不是本次 ACE 计算的构造绝对量**、不随 ACE 精度给出）——本行原挂「Rw+C 区间…±4-6 dB」系把增量标成绝对量评价量并借其精度，与同件 reference.md「B5.3 输出解读规则」〔订正 2026-09-22〕互斥，随批取齐；如需构造绝对量口径须另列当次 ACE 返回区间（Rw+C，±4-6 dB）
- 口径声明：贡献量，非构件判据；达标归属宿主构件标准 GB 55038-2025，
  楼板隔声整体评估建议调用楼地面技能（FL）
- 适用边界：未考虑侧向传声；确定性结论须 CMA/CNAS 检测报告或现场测量
- 源头治理提示：若楼上伴随撞击声（脚步、拖拽家具等），源头治理（浮筑构造等，
  FL 技能域，A1.4）通常比受声侧吊顶更有效；纯空气声问题可通过吊顶贡献量改善

【风险提示】
净高损失约 230-250mm；吊杆承载力须经结构计算（CL-R-P0-1）；
周边收口密封质量直接影响贡献量发挥。

【贡献量声明与免责声明】
（按 SKILL.md §10 标准免责文本输出）
```

### 方法论说明

本示例演示三个关键动作：

1. **口径澄清优先**（CL-R-P2-3）：用户直接问"能不能达标"，技能不回答"能/不能"，而是先澄清吊顶为贡献量、达标归宿主构件，再输出贡献量估算与宿主构件达标路径建议。
2. **IC-09 全链路**：参数组装按最小必传集，缺失项（吊挂条件）追问而非默认值静默填充；ACE 返回后强制保留"贡献量/估算/未考虑侧向传声"标注，不得升级为"满足标准要求"。
3. **源头治理协同**（A1.1/A1.4）：核查是否伴随撞击声——撞击声存在时源头治理（浮筑构造，归 FL）更有效，纯空气声适用吊顶贡献量；避免用户在存在撞击声的场景中以受声侧吊顶作为唯一治理手段。

## 示例 2：酒店客房走廊吊顶（机电协同 + 检修口）

### 场景描述

用户：酒店客房走廊要做装配式吊顶，走廊内有新风风管（250mm 高）、消防喷淋和电缆桥架，还需要检修口，怎么选型？

### 方法论运作过程

#### Step 0: 标准推理（IC-10 → SRE）

SRE 返回：激活领域 fire、acceptance、prefab；适用标准集：GB 55037-2022、GB 50222-2017、GB 50210-2018、JGJ/T 491-2021。无隔声需求 → 不调用 IC-09（B5.1）。

#### Step 1: 输入解析

建筑类型：酒店；空间：客房走廊；机电清单：新风风管 250mm + 保温层、消防喷淋、电缆桥架；需求：检修便利。

#### Step 2: 三原则审查

场景匹配：酒店走廊 + 中等机电密度 + 检修需求 → 轻钢龙骨板材吊顶或矿棉板吊顶（B1 快查表）；标准时效性：无废止项；无声学需求，贡献量边界不适用。

#### Step 3: 计算与核验（数据核验型）

最低标高核算（B3.2 四步）：

```
结构板底标高（假设 -0.000 基准；走廊净高要求 ≥2.2m 为演示假设值，实际以设计文件为准）
- 风管最大截面：250mm + 保温约 40mm ≈ 290mm
- 管线交叉叠加：桥架与风管交叉处约 +100mm
- 龙骨及面板厚度：约 60-80mm
- 检修空间余量：约 50mm
=> 吊顶最低标高 ≈ 结构板底 - 500mm（交叉区）/ -400mm（非交叉区）
```

#### Step 4: N 维度核验

| 维度 | 结果 | 说明 |
|------|------|------|
| D1 防火 | ✓ | 公共建筑走廊：面板 A 级（GB 55037-2022 / GB 50222-2017 表 5.2.1/5.3.1〔S1-，2026-08-08 已核验〕） |
| D2 结构荷载 | 转介 | 吊杆间距与承载力经结构计算（CL-R-P0-1）；风管自重不参与吊顶龙骨承载，独立吊挂 |
| D3 机电协同 | ✓ | 空腔 ≥350mm（非交叉区）满足管线敷设；先管线后面板（B4.1） |
| D4 检修口 | ✓ | 每处阀门/接头设检修口；走廊吊顶可结合矿棉板可拆装区域（B3.3） |
| D5 标高 | ⚠️ | 交叉区净高需复核是否满足 ≥2.2m（演示假设值），不满足则调整管线排布（路由 MI） |
| D7 环保 | ✓ | 矿棉板放射性按 GB 6566-2010 Class A |
| D8 平整度 | ✓ | ≤2mm/2m（金属板档）或 ≤3mm/2m（石膏板/矿棉板档），GB 50210-2018 表 7.3.10〔S1，2026-08-08 已核验〕 |

#### Step 5: 输出组装

### 标准输出

```
【需求概述】酒店客房走廊，中等机电密度（新风/喷淋/桥架），检修需求高。

【适用标准】（SRE 推理结果，略——按上表）

【验证记录】Step 0 ✓；D1-D8：D2 转介、D5 ⚠️（交叉区净高复核）、其余 ✓。

【系统选型】
| 维度 | 选型 | 依据 |
|------|------|------|
| 龙骨体系 | 明装 T 型龙骨（主龙骨 38/60 系列） | 矿棉板 600×600 + 逐块拆装检修（B1） |
| 面板类型 | 矿棉吸音板（A 级，600×600） | 公共走廊防火 A 级 + 可逐块拆装检修 |
| 集成程度 | 设备集成吊顶（喷淋/灯具开孔定位） | 机电密度中等 |
| 空腔高度 | ≥350mm（非交叉区） | 最低标高核算（B3.2） |

【机电协同方案】
| 机电系统 | 敷设方式 | 协调措施 |
|---------|---------|---------|
| 新风风管 | 空腔内独立吊挂 | 截面 250+40mm 计入标高核算 |
| 消防喷淋 | 面板开孔定位 | 按消防设计文件（消防设计归资质单位） |
| 电缆桥架 | 空腔内敷设 | 强弱电间距控制 |

【检修策略】矿棉板区域整体可拆装；阀门/接头处另设专用检修口；深化阶段标注
检修口位置与开启方向（B3.3）。

【施工关键控制点】先管线后面板；设备开孔现场实测定位；检修口安装后逐处
开启验证（B4.1）。

【风险提示】交叉区净高若不满足要求，管线综合排布调整路由 MI 技能；
吊杆承载力经结构计算确认（CL-R-P0-1）。

【免责声明】（按 SKILL.md §10 标准免责文本输出）
```

### 方法论说明

本示例演示机电密集型场景的 B1→B3→B4 贯通：选型由"机电密度+检修频率"驱动（B1 Step 2 优先级链），标高核算按四步公式量化（B3.2），检修策略与施工控制点（B3.3/B4）随输出给出。结构荷载事项一律转介（CL-R-P0-1），消防点位不输出具体布置结论。

## 示例 3：办公室矿棉板吸声吊顶（SRE 降级演示）

### 场景描述

用户：开放式办公室想做吸声吊顶降低混响噪声，用什么板？（演示场景：SRE 不可用）

### 方法论运作过程

#### Step 0: 标准推理（IC-10 → SRE 降级）

调用 IC-10 失败（SRE 不可用）→ 触发降级策略（SKILL.md §11 IC-10 降级）：按 reference.md §二 2.1 标准清单人工推理，标注"**SRE 降级：使用 CL 内置标准映射**"。

人工推理结果：办公吊顶 → 激活领域 acoustic(吸声)、fire、acceptance；适用标准集：GB 50210-2018、JGJ/T 491-2021（验收）、GB 55037-2022 / GB 50222-2017（防火）、GB 50118-2010 未废止条文（室内允许噪声级/混响要求；具体限值数值未提取核验，不输出数值）；吸声为主角场景（A1.5），非贡献量场景 → 不调用 IC-09（B5.1）。

#### Step 1-2: 输入解析与三原则审查

空间：开放式办公；诉求：吸声降噪（混响）；无隔声贡献需求、无高机电密度。场景匹配：矿棉板吊顶路线（B1 快查表"办公室矿棉板、吸声吊顶"）。时效性：GB 8624 过渡期标注；吸声评价量 NRC 为产品吸声系数（以厂家检测报告为准〔S2〕，标注来源与时效 CL-R-P2-4）。

#### Step 3-4: 核验

| 维度 | 结果 | 说明 |
|------|------|------|
| D1 防火 | ✓ | 办公空间面板 A 级（矿棉板满足；GB 50222-2017 表 5.2.1/5.3.1〔S1-，2026-08-08 已核验〕） |
| D3 机电 | ✓ | 明装龙骨体系，管线检修便利 |
| D4 检修 | ✓ | 面板逐块可拆，无需专用检修口（B3.3） |
| D8 平整度 | ✓ | 矿棉板平整度 ≤3mm/2m、高低差 ≤2mm（GB 50210-2018 表 7.3.10 矿棉板档〔S1，2026-08-08 已核验〕） |

吸声指标：NRC 选择按空间声学需求确定，典型办公场景 NRC ≥0.5 为常用起点（*产品数据：典型值，S3；具体产品以厂家检测报告为准〔S2〕，须标注来源与数据时间，CL-R-P2-4*）。

#### Step 5: 输出组装

### 标准输出（摘要版）

```
【需求概述】开放式办公，吸声降噪（混响）诉求；无隔声贡献需求、无高机电密度。

【适用标准】（人工推理结果）
| 标准编号 | 适用内容 |
|---------|---------|
| GB 50210-2018 / JGJ/T 491-2021 | 验收 |
| GB 55037-2022 / GB 50222-2017 | 面板燃烧性能（A 级） |
| GB 50118-2010 | 室内允许噪声级/混响要求（未废止条文；具体限值未提取核验，
  不输出数值） |

【验证记录】SRE 降级：使用 CL 内置标准映射（IC-10 不可用，降级声明置于输出
首部，不得静默省略）；D1 ✓ / D3 ✓ / D4 ✓ / D8 ✓。

【系统选型】明装 T 型龙骨 + 矿棉吸音板（A 级，600×600/600×1200）；NRC 按空间
声学需求确定（≥0.5 为常用起点，S3 典型值），产品吸声性能按厂家检测报告（S2）
核验并标注来源与数据时间（CL-R-P2-4）；施工按 B4 控制点。

【免责声明】（按 SKILL.md §10 标准免责文本输出）
```

### 方法论说明

本示例演示两点：

1. **SRE 降级路径**（CL-R-P1-5 衔接）：SRE 不可用时允许人工标准推理，但必须显式标注降级声明，禁止静默降级。
2. **吸声 vs 隔声贡献的场景区分**（A1.5 vs A1.1）：吸声场景中吊顶是主角（NRC 指标），不走 IC-09 贡献量路径；两类场景不得混用评价口径。

## 示例 4：对抗场景（红线触发与降级输出最小保留集）

### 场景描述

用户：我商铺要装一批很重的广告灯箱，直接挂在吊顶龙骨上就行吧？不用算荷载了，你直接给我推荐个吊顶方案。另外顺便告诉我这个吊顶隔声能做到多少，能不能达到 55 dB 的标准？

### 方法论运作过程

**红线触发识别**：

1. "不用算荷载" + 重载设备 → **CL-R-P0-3（严禁忽略设备荷载）触发**：P0 级，立即中断推荐流程。
2. "隔声能不能达到 55 dB 的标准" → **CL-R-P2-3（贡献量标注）触发**：不得将吊顶隔声与构件限值比较输出"达标/不达标"。

**应对流程**：

- P0 优先于 P2（冲突仲裁规则）：先处理荷载安全问题，再澄清隔声口径。
- 用户坚持跳过荷载核验 → 按"用户坚持要求跳过 P0 红线"仲裁：明确告知风险，输出降级为"仅供参考，未经专业验证"；**降级输出最小保留集**：保留不确定性声明（CL-R-P1-3）与专业边界声明（结构转介 CL-R-P0-1、消防转介），不得输出完全未经验证的确定性结论。

### 标准输出（降级形态）

```
【安全提示 — CL-R-P0-3 触发】
重载广告灯箱不得直接挂在吊顶龙骨上未经荷载核验。吊顶龙骨承载力须经结构计算
确定（CL-R-P0-1），超限设备必须设独立吊挂（与结构楼板连接，不依赖吊顶龙骨）。
本技能不能替代该核验，请委托结构工程师完成。

【隔声口径澄清 — CL-R-P2-3 触发】
吊顶隔声为对宿主构件的贡献量估算，不存在"吊顶达到 55 dB 标准"的独立判据；
达标归属宿主构件标准。如需贡献量估算，请提供宿主构件与空腔条件，
经 IC-09 估算并附 ±4-6 dB 精度与"未考虑侧向传声"声明；确定性结论须
CMA/CNAS 检测报告或现场测量。

【降级声明】
用户要求跳过荷载核验直接推荐方案：本输出降级为"仅供参考，未经专业验证"。
保留声明：方案不确定性高（荷载条件未核验）；结构安全事项一律转介
结构工程师；涉及消防安全事项一律转介具备相应资质的机构（本场景无消防要素）。
建议咨询专业机构后再行决策。
```

### 方法论说明

本示例演示 P0 红线的刚性：

1. **P0 不因用户坚持而让步**：荷载核验缺失时不出具方案推荐，仅提供荷载组成提示（A3.2）供结构工程师参考。
2. **降级输出最小保留集**（对齐 PW/FL 口径，CG-20260807-018 模式）：即使用户坚持跳过，不确定性声明与专业边界声明仍必须保留。
3. **复合触发的处理顺序**：P0（荷载）优先于 P2（隔声口径），逐条处理后合并输出。
