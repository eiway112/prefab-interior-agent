## 一、定义与分类框架

### 1.1 系统定义

**装配式吊顶系统**：在建筑主体结构下方，由工厂预制的龙骨构件和面板模块，在现场主要采用干法装配而成的，满足功能、设备和装饰要求的集成化顶面系统（参照 JGJ/T 491-2021 相关定义）。

**系统三要素**：

| 要素 | 组成 | 功能 |
|------|------|------|
| 支承体系 | 吊杆（含弹性吊挂/减振吊钩）+ 龙骨（主/次龙骨） | 承载与定位 |
| 空腔功能层 | 龙骨与面板间空腔（机电管线敷设空间） | 管线分离与设备集成 |
| 面板体系 | 铝扣板/矿棉板/石膏板/硅酸钙板/金属复合板/GRG 等 | 防火、声学、装饰 |

### 1.2 三维分类矩阵

| 维度 | 分类 | 说明 |
|------|------|------|
| **龙骨体系** | 明装龙骨（T型/三角龙骨）、暗装龙骨（卡式/嵌入式）、轻钢龙骨（U型/C型）、专用集成龙骨 | 决定面板安装方式和检修便利性 |
| **面板类型** | 铝扣板/铝方通、矿棉板、硅酸钙板、石膏板、金属复合板、GRG造型板 | 决定防火等级、声学性能和装饰效果 |
| **集成程度** | 纯装饰吊顶、设备集成吊顶（含照明/风口/喷淋）、模块化设备带吊顶 | 决定机电协同复杂度和检修策略 |

### 1.3 四条技术路线

| 路线 | 构造特征 | 空腔范围 | 核心适用场景 |
|------|---------|---------|------------|
| 集成模块化吊顶 | 标准化模块（300×300/600×600/600×1200mm），面板与功能模块集成 | 100-400mm | 厨卫、走廊等小跨度空间 |
| 轻钢龙骨板材吊顶 | U型/C型轻钢龙骨+石膏板/硅酸钙板 | 150-600mm+ | 大面积办公、酒店客房，管线分离 |
| 金属板吊顶 | 铝扣板、铝方通、铝格栅 | 100-400mm | 商业、交通、医疗洁净空间 |
| 矿棉板吊顶 | 明装/暗装龙骨+矿棉吸音板 | 150-400mm | 办公、教育空间（吸声） |

> 各路线隔声/吸声特性、机电密度与检修策略差异详见 §四 B1 选型决策树。

### 1.4 用户表述 → 分类映射

| 用户表述 | 映射方向 |
|---------|---------|
| 厨卫吊顶、铝扣板、集成吊顶 | 集成模块化吊顶路线 |
| 办公室矿棉板、吸声吊顶 | 矿棉板吊顶路线（吸声场景，§三 A1.5） |

| 隔音吊顶、楼板隔声吊顶 | 轻钢龙骨板材路线 + 隔声贡献路径（§三 A1，须经 B2 验证，贡献量口径） |

### 2.2 引用规则与标准冲突处理

**冲突处理三原则**：

1. 层级优先：L1 强制性国标 > L2 推荐性标准 > L3 图集/导则 > L4 产品标准
2. 时效优先：同层级以最新发布/实施版本为准（含 GB 8624-2012→2025 过渡期标注）
3. 专项优先：通用标准与专项标准冲突时，以专项标准为准

**条文号引用规则**（对应红线 CL-R-P1-1）：

- 引用的标准条文号必须真实存在且经核验；未经核验的条文号一律改用"标准名称+章节主题"描述，并标注"待 S1 核验"

## 三、原理红线层（A层）

> **使用说明**：A 层内容为 CL 技能不可违背的物理原理和规范底线。任何输出若与 A 层矛盾，必须以 A 层为准并修正。

### A1 声学原理与贡献量定位红线

> **本节是 CL 技能最易被误读的方法论域**：吊顶的声学性能是对宿主构件（楼板、分户墙）隔声的**改善贡献量**，本身不构成独立隔声判据；最终达标判断归宿主构件及其适用标准。对应策划红线 CL-R-P2-3（输出须标注"贡献量/估算"，不得表述为构件隔声判据或检测值）。

#### A1.1 贡献量定位（方法论红线）

| 声学问题 | 宿主构件 | 吊顶的角色 | 达标判据归属 |
|---------|---------|-----------|-------------|
| 楼上空气声传至楼下 | 楼板 | 隔声吊顶提升楼板空气声隔声（贡献量） | GB 55038-2025（住宅，强制性）/ GB 50118-2010（非住宅未被废止条文）〔S1〕 |
| 分户墙两侧空气声 | 分户墙 | 分户墙一侧吊顶参与墙体隔声系统（贡献量） | GB 55038-2025（住宅分户构件）〔S1〕 |
| 楼板撞击声 | 楼板 | 弹性吊挂吊顶改善撞击声（贡献量，源头治理优先） | GB 55038-2025（住宅 L'nT,w）〔S1〕；源头减振与浮筑构造归 FL 技能 |
| 室内音质（混响/清晰度） | 空间本身 | 吸声吊顶是主要调控手段（本域吊顶是主角，非贡献量） | GB 50118-2010（学校/医院/办公等非住宅条文仍有效）〔S1〕 |

> **红线提醒**：前三类场景中，吊顶隔声输出必须强制标注"贡献量/估算，非构件判据"；不得将吊顶估算值与构件限值直接比较后输出"满足/不满足"结论，达标判断归宿主构件标准（对应 IC-09 契约使用约束："ACE 输出始终标注'专业估算'，吊顶技能不得升级为'满足'"）。

#### A1.2 空气声隔声贡献机制

隔声吊顶对楼板/分户墙空气声隔声的贡献机制〔v1 知识库基线 + 物理原理，机制描述为行业共识；量化数值见 S 级标注〕：

- 吊顶与结构楼板之间形成空气层，构成双叶构造，增加隔声能力
- 空腔内填充吸声材料（岩棉/玻璃棉）可进一步提升隔声量
- 弹性吊挂（减振吊钩）可削弱声桥，提升隔声与撞击声改善效果
- 吊顶板面密度越大、周边收口密封越好，隔声贡献越大
- v1 经验区间：增加吊顶可提升楼板隔声量约 5-15 dB〔S3 经验数据：取决于吊顶构造、空腔填充和密封质量，具体以实验室检测为准〕

**已知短板**：

- **侧向传声**：吊顶与墙体收口处的侧向传声是隔声吊顶的常见短板，未纳入估算模型（IC-09 契约要求响应必须含此声明）
- **刚性声桥**：刚性吊杆、未解耦的龙骨连接构成声桥，系统性降低贡献量
- **密封缺口**：吊顶周边收口不密封时，缝隙漏声可使贡献量大幅下降（缝隙危害原理同 PW/FL 域）

#### A1.3 计算路由与估算口径（仓内 SOT）

**路由规则**：CL 不自行计算隔声量。空气声隔声估算经 IC-09 调用 ACE（acoustic-calculation-engine）：

| 要素 | 口径 |
|------|------|
| 评价量 | 吊顶场景使用 Rw+C / Rw+Ctr（不使用现场量 DnT,w；DnT,w 属宿主构件现场验收量）〔IC-09 Schema〕 |
| 构造类型枚举 | 单层板 / 双层板+空腔 / 隔声吊顶 / 其他〔IC-09 v1.5.3〕 |
| 最小必传参数 | 吊顶面板（材料类别+层描述）、空腔深度、吊杆类型、评价量；填充材料、吊杆间距、密封方式可选〔IC-09 字段约束表〕 |
| 估算精度 | 约 ±4-6 dB，输出为"专业估算"区间〔IC-09 契约〕 |
| 强制标注 | "贡献量/估算/未考虑侧向传声"；不得升级为"满足"〔IC-09 使用约束〕 |
| 确定性输出 | 竣工验收与确定性合规判断须 CMA/CNAS 检测报告或现场测量，ACE 估算不得替代〔CG-20260807-011 仲裁结论〕 |

**物理模型适用域**〔ACE reference.md SOT，CG-20260807-011〕：

- 吊顶与结构楼板构成**双叶构造**：禁用单叶质量定律简化式（M1），须路由 M3/MSM 双叶模型
- 质量定律简化式 Rw≈20lg(m)+K 统一取 K=0，且仅限单板概念比较，不得用于吊顶系统估算
- 面密度 <30 kg/m² 轻质构造区 M1 系统性低估已知，禁止以经验值静默覆盖物理计算值

**降级策略**〔IC-09 契约，IT-2 重锚 2026-08-08；PL-045 补触发判据〕：ACE 不可用（须按 SKILL.md §12「降级触发判据（先探测，后降级）」探测确认；"调用失败"仅覆盖探测态②，技能条目缺失①与文件加载失败③同属触发条件）时，以 A1.2 v1 经验区间（吊顶提升楼板隔声量约 5-15 dB〔S3〕）+ 定性贡献机制说明执行简化估算，输出标注逐字含契约降级列字面"简化估算（隔声计算引擎暂不可用）"并保留全部 A1 标注纪律；经验区间亦不可用时仅输出定性机制说明 + 建议实验室检测，不输出任何数值。

#### A1.4 撞击声贡献原理

- 楼板撞击声以结构传声为主，**源头治理优先**（浮筑构造、弹性隔离层归 FL 技能域）
- 弹性吊挂吊顶（减振吊钩 + 空腔填充）在受声侧提供补充改善，属贡献量
- 评价量方向：L'nT,w / Ln,w 数值越低越好，与 Rw 方向相反，不得混用
- 住宅楼板撞击声限值 L'nT,w ≤ 65 dB〔GB 55038-2025 **第 6.1.2 条第 2 款**，逐字「卧室、起居室楼板的计权标准化撞击声压级不应大于 65dB」，2026-09-27 官方出版物逐字核验（S1），正文第 16 页／PDF p022，凭据 `核验成果/GB 55038-2025_核验报告_20260927.md` §二〕

#### A1.5 吸声原理（吊顶为主角的场景）

- 吸声吊顶（矿棉板、穿孔板等）通过表面吸声降低室内混响、提升语言清晰度，适用于教室、会议室、办公开敞区等
- 吸声性能以 NRC（降噪系数）或吸声系数表征；v1 知识库载矿棉吸音板 NRC ≥ 0.5 为产品典型值〔S3 产品数据：典型值，具体以厂家检测报告为准〕
- 学校、医院等建筑的室内允许噪声级与混响要求见 GB 50118-2010 相应条文〔S1 标准存在性已核验（标准现行、非住宅条文有效）；**具体限值数值本仓尚未提取核验，阶段 7 前不得输出具体数值**〕
- 吸声与隔声是两类不同性能：吸声改善本室音质，不直接等同于对邻室的隔声改善，不得混淆表述

### A3 结构安全与荷载边界（转介红线）

#### A3.1 结构计算边界

**CL-R-P0-1（P0 红线）**：严禁替代结构计算。吊杆承载力、龙骨跨度、抗震构造等结构安全事项不得给出最终设计结论，一律转介结构工程师。标准应对话术："吊顶承载力需经结构计算确定，本技能仅提供选型参考，具体设计应委托结构工程师完成。"

#### A3.2 吊顶荷载组成与独立吊挂原则

| 荷载项 | 性质 | 口径 |
|--------|------|------|
| 吊顶自重（龙骨+面板） | 恒载 | 按构造组成计算〔原理〕 |
| 设备荷载（灯具/风口/检修设备等） | 附加荷载 | 超过面板/龙骨承载能力时须独立吊挂〔原理 + CL-R-P0-3〕 |
| 检修荷载（上人吊顶） | 活载 | ≥1.0 kN/m²〔S3 行业经验值；经 2026-08-08 核验 GB 50009-2012 全文无"上人吊顶"对应条文（v1 归因有误，已删除），取值以结构设计为准〕 |

**灯具独立吊挂**：灯具荷载 >3kg 需独立吊挂（不得由面板/龙骨承托）〔S1-·GB 50303-2015 第 18.1.2 条第 3 款，2026-08-08 核验：质量大于 3kg 的悬吊灯具应固定在螺栓或预埋吊钩上，其直径不应小于灯具挂销直径且不应小于 6mm。v1 记载"第 19.1.3 条"为 2002 版旧编号，已更正。注：同章 18.1.1 条自 2022-10-01 废止（GB 55024-2022），引用时避开〕。

**CL-R-P0-3（P0 红线）**：严禁忽略设备荷载。未核实荷载不得推荐吊顶方案。

#### A3.3 施工控制边界（荷载相关项）

吊杆间距、龙骨间距等控制参数必须经结构计算与厂家荷载表确定，本技能知识库中的参考值均为 S3 经验值：

| 主龙骨间距 | ≤1200mm（按板材规格确定） | 〔S3〕 |
| 次龙骨间距 | ≤600mm（石膏板）/ ≤400mm（潮湿环境） | 〔S3〕 |

### A5 机电协同框架（原理层）

> 方法论细节（空腔高度计算流程、冲突排查、检修口布置方法）归 B3 机电协同与检修口方法论（阶段 3）。本节仅列原理与红线。

#### A5.1 管线分离与空腔定位

**管线分离原则**：装配式吊顶应实现"结构—管线—装饰"三层分离——管线敷设在吊顶空腔内，不嵌入结构楼板；面板可独立拆卸检修，不影响管线；管线检修不破坏面板。〔JGJ/T 491-2021 装配式内装修总纲要求的具体化，S1 标准存在性已核验〕

吊顶空腔是装配式装修机电管线的主要敷设空间，各系统影响概览〔v1 知识库基线〕：

| 机电系统 | 典型管线/设备 | 对吊顶的影响 |
|---------|-------------|------------|
| 暖通空调 | 风管、风机盘管、新风口、回风口 | 决定吊顶最低标高和空腔高度 |
| 消防 | 喷淋头、烟感、广播、应急照明 | 面板开孔定位 |
| 电气照明 | 灯具、线槽、接线盒 | 面板开孔/嵌入式安装 |
| 弱电 | 网络、监控、门禁 | 线槽/桥架敷设 |
| 给排水 | 冷凝水管、排水管 | 坡度要求 |

#### A5.2 最低标高原理

吊顶最低标高 = 结构楼板底标高 − 管线最大截面高度 − 管线交叉叠加高度 − 龙骨及面板厚度 − 检修空间余量〔v1 知识库基线，原理公式〕

常见管线截面参考〔S3 经验数据，具体以施工图为准〕：空调风管 200-600mm（含保温）；消防喷淋主管 DN100-DN150；电缆桥架 100-300mm；排烟风管 250-800mm（按防烟分区计算）。

### B3：机电协同与检修口

#### B3.1 协同范围与边界

- **归 CL**：空腔高度决策、面板开孔定位、检修口布置、吊顶与设备点位收口
- **归 MI**：管线综合排布、跨部品冲突协调、安装顺序编排（触发时调用 prefab-mep-integration-system）
- 协同输入：机电系统清单（暖通/消防/电气/弱电/给排水）+ 各系统管线截面与点位要求

#### B3.2 最低标高核算流程

```
吊顶最低标高 = 结构楼板底标高
             − 管线最大截面高度（含保温）
             − 管线交叉叠加高度
             − 龙骨及面板厚度
             − 检修空间余量
```

〔v1 知识库基线，原理公式〕执行步骤：

1. 汇总空腔内全部管线截面（常见参考值见 A5.2，S3，以施工图为准）
2. 识别最大截面管线（通常为风管或排烟风管）与交叉叠加点
3. 叠加龙骨面板厚度与检修余量，得出吊顶最低标高
4. 与建筑净高要求比对：不满足时按"管线改路由（归 MI）→ 截面优化 → 空腔压缩极限核查"顺序处置，不得以牺牲检修空间为唯一手段

#### B3.3 检修策略与布置

检修方式选型〔v1 知识库基线〕：

| 检修方式 | 适用场景 | 设计要点 |
|---------|---------|---------|
| 面板整体可拆卸 | 矿棉板、铝扣板、金属格栅 | 面板与龙骨卡扣/搁置连接，无需工具即可拆装 |
| 专用检修口 | 石膏板/硅酸钙板封闭吊顶 | 每 ≥15m² 或每个阀门/接头处设检修口〔S3 经验数据：行业通用做法，具体以设计要求为准〕 |
| 模块化设备带 | 医院、实验室 | 设备带独立于装饰面板，可单独开启维护 |
| 走道式检修 | 大型公建（机场、车站） | 吊顶上方设检修马道，面板无需拆卸 |

布置核验规则：

- 空腔内每个阀门、接头、可维护设备必须有可达检修路径（D4 核验项）
- 检修口开启方向与管线无冲突（A6.3 通病防治）
- 封闭吊顶（石膏板/硅酸钙板）未设检修口即视为 D4 不通过

#### B3.4 机电点位协调要点

〔v1 知识库基线；条文号类依据的核验状态见 A5.3〕

| 机电系统 | 典型管线/设备 | 对吊顶的影响 | 协调要点 |
|---------|-------------|------------|---------|
| 暖通空调 | 风管、风机盘管、新风口、回风口 | 决定吊顶最低标高和空腔高度 | 风管截面尺寸+保温层+安装间距 |
| 消防 | 喷淋头、烟感、广播、应急照明 | 面板开孔定位 | 喷淋头间距、烟感距墙按消防设计文件（消防设计归资质单位，A2.5） |
| 电气照明 | 灯具、线槽、接线盒 | 面板开孔/嵌入式安装 | 灯具 >3kg 独立吊挂（A3.2） |
| 弱电 | 网络、监控、门禁、广播 | 线槽/桥架敷设 | 强弱电间距控制 |
| 给排水 | 冷凝水管、排水管 | 坡度要求 | 坡度 ≥0.003，不得穿越电气设备和灯具正上方（A5.3） |

> **模数化协调**：吊顶模块尺寸与设备布点协调（模数化设计），设备开孔按模块网格定位，避免非模数现场切割（v1 深化方向承接项）。

### B4：施工控制

#### B4.1 施工流程原则

1. 先管线后面板：机电管线安装、试压/验收完成后再封面板（A6.3 设备开孔错位防治）
2. 吊杆/龙骨间距必须经结构计算与厂家荷载表确定后施工（A3.3，S3 参考值不得直接作为施工依据）
3. 设备开孔现场实测定位，先装管线后开孔
4. 检修口在深化阶段预留，安装后逐处开启验证
5. 隔声吊顶专项：弹性吊挂安装、空腔填充、周边收口密封按深化节点执行（密封质量直接影响 A1.2 贡献量）

#### B4.2 关键控制点

〔v1 知识库基线，S3 行业通用参考值；吊杆间距和龙骨间距必须经结构计算确定〕

| 序号 | 控制项目 | 参考标准 | 检验方法 |
|------|---------|---------|---------|
| 1 | 吊杆间距 | ≤1200mm（主龙骨方向）；具体以设计计算为准 | 尺量 |
| 2 | 主龙骨间距 | ≤1200mm（按板材规格确定） | 尺量 |
| 3 | 次龙骨间距 | ≤600mm（石膏板）/≤400mm（潮湿环境） | 尺量 |
| 4 | 吊杆垂直度 | 偏差≤2mm | 吊线 |
| 5 | 面板安装 | 无翘曲、无破损、接缝均匀 | 目测+尺量 |
| 6 | 设备开孔 | 位置偏差≤2mm，边缘整齐 | 尺量 |
| 7 | 检修口 | 位置正确、开启灵活、密封良好 | 手动开启检查 |

#### B4.3 质量通病防治

施工过程中的通病—原因—防治对照见 A6.3。施工交底应将 A6.3 五项通病（翘曲/接缝开裂/下坠/开孔错位/检修口无法开启）逐条列入预防项。

### B5：隔声贡献估算（IC-09 调用规范）

> 本节是 B2 Step 3 隔声路径的执行细则。物理原理与红线见 A1；契约字段详见 interface-contracts.md IC-09。

#### B5.1 调用时机

- 用户提出隔声吊顶、楼板/分户墙隔声改善、酒店客房/住宅分户等空气声隔声诉求时
- **不调用**：纯吸声诉求（室内音质）走 A1.5 路径；撞击声诉求先声明源头治理优先（A1.4），吊顶侧改善仅作补充说明
- 调用前必须完成口径澄清：吊顶输出为贡献量，达标判断归宿主构件标准（A1.1）

#### B5.2 参数组装（最小必传集）

| 参数 | 要求 | 获取方式 |
|------|------|---------|
| 发起方标识 | CL | 固定 |
| 评价量 | Rw+C 或 Rw+Ctr（吊顶场景不使用 DnT,w） | 按宿主构件场景路由 |
| 构造类型 | 单层板 / 双层板+空腔 / 隔声吊顶 / 其他 | 按深化构造判定 |
| 面板层 | 材料类别 + 层描述（厚度/层数） | 深化设计；产品参数以厂家报告为准〔S2〕 |
| 空腔层 | 深度_mm 必填（0-600，隔声吊顶含原顶空腔）；填充材料/填充率可选 | 深化设计 |
| 吊挂系统 | 刚性吊杆 / 弹性吊挂（减振吊钩）等 | 深化设计 |
| 收口密封 | 密封处理方式（可选，影响密封评估） | 深化节点 |

缺失必填参数时：ACE 返回"参数不足"并列出缺失项，CL 向用户补询，不得以默认值静默填充。

#### B5.3 输出解读规则

- ACE 返回的**数值区间是构造绝对量**：IC-09 响应字段 `计算结果.隔声估算区间.评价量` 的枚举为 Rw+C / Rw+Ctr（见 `../shared/interface-contracts.md` IC-09 响应字段约束），单位 dB 是**计权隔声量本身**，不是"吊顶对宿主构件的贡献量（增量）"。A1.1 的"贡献量"是**定位**标注（吊顶不构成独立构件判据），与本句的**量纲**标注不矛盾但不可混用。CL 转述时除 A1.3 强制标注「贡献量/估算/未考虑侧向传声」外，须另注明本次区间数值为**构造绝对量口径**
- **绝对量与增量两套量纲不得互推，不得夹取**〔订正 2026-09-22，取代原 IT-3 保守封顶规则〕：A1.2 的 v1 经验区间 5-15 dB 是"加装吊顶后宿主构件隔声量的**提升量 Δ**"（增量），与 IC-09 的绝对量不是同一物理量。原规则「下限 = min(ACE 下限, 5 dB)，上限 = min(ACE 上限, 15 dB)」把绝对区间截入增量区间（ACE 返回 46-52 dB 会被压成 5-15 dB），属口径混用，故取消。改为：
  - 对外**分列**输出：① 构造绝对量估算区间（ACE 原始区间 ±4-6 dB）；② 经验提升量区间 5-15 dB〔S3〕，并声明其来源为 A1.2 经验值、**不是本次计算结果**；
  - 禁止取交集、夹取、或以其一替代其二；
  - 确需由绝对量得到贡献量时，须另有宿主构件原构造在**同一评价量**下的 Rw+C 基准值（检测报告编号或图集页码，须标明来源），按 Δ = Rw+C(加吊顶后) − Rw+C(原构件) 计算；缺基准值即不折算，只分列。
- **保守性披露保留**（原 IT-3 的合理部分，改为不改写数值的披露）：ACE U-01 声明现场侧向传声未纳入模型，实际构件隔声量可能低于估算值 5-15 dB → 以"偏低风险披露"另句输出，**不得据此截断或下修区间数值**
- 吻合效应风险等级（无/低/中/高）一并转述；中/高风险时提示面板材质与厚度调整方向
- 密封评估结论为"无法判断"时，如实输出并提示收口密封对隔声吊顶影响显著
- **禁止**：将估算值与构件限值直接比较输出"满足/不满足"；将估算值表述为检测值或验收依据（确定性输出须 CMA/CNAS 检测报告或现场测量，A1.3）

#### B5.4 降级策略

- ACE 不可用（按 SKILL.md §12 判据探测确认，含调用失败／技能条目缺失／文件加载失败三态）：以 A1.2 v1 经验区间（5-15 dB〔S3〕）+ 定性贡献机制说明执行简化估算，输出标注逐字含契约降级列字面"简化估算（隔声计算引擎暂不可用）"，并保留全部 A1 标注纪律〔IT-2 重锚，与 A1.3 降级策略一致〕
- 简化估算亦不可用时：仅输出贡献机制定性说明（A1.2）+ 建议实验室检测，不输出任何数值

#### B5.5 估算记录模板（输出附段）

```
【隔声贡献估算记录】
调用路径：IC-09 → ACE（或：简化估算/SRE降级声明）
构造描述：构造类型 / 面板层 / 空腔深度与填充 / 吊挂系统 / 收口密封
估算结果：Rw+C（或 Rw+Ctr）估算区间 ±4-6 dB〔数值为构造绝对量口径，非对宿主构件的增量〕
风险识别：吻合效应风险等级；密封评估结论
边界声明：贡献量/估算，非构件判据；对宿主构件的提升量按 A1.2 经验区间 5-15 dB〔S3〕**分列**给出，不由上方绝对量区间夹取或换算（缺原构件同评价量 Rw+C 基准值时不得折算）；未考虑侧向传声与吊顶内机电噪声；
          达标归属宿主构件标准（GB 55038-2025 / GB 50118-2010 未废止条文）；
          确定性结论须 CMA/CNAS 检测报告或现场测量
```
