# 示例输出

这里的四份文件是**技能的真实应答样例**：装进平台后提问，拿到的是这种结构。它们不是宣传稿，也不是项目交付文件。

| 示例 | 技能 | 问的是 |
|---|---|---|
| [01 隔墙方案验证](01-partition-wall-verification.md) | `prefab-partition-wall-solution` | 住宅分户墙的隔声与耐火怎么验证 |
| [02 厨卫选型对比](02-bathroom-kitchen-selection.md) | `prefab-bathroom-kitchen-system` | 酒店客房整体卫浴三条技术路线怎么选 |
| [03 机电红线拦截](03-mep-redline-check.md) | `prefab-mep-integration-system` | 给水管直接穿过防水层，会被怎么拦、该怎么做 |
| [04 标准边界核验](04-standards-review.md) | `prefab-standards-reviewer` | 指标表里的「≥」与「＞」边界怎么核 |

## 这些文件是怎么来的

由开发仓的派生器从各技能自己的 `examples.md`（位于 [`skills/`](../skills/)）中**原样抽取**（锚点命中即取、锚点缺失即报错），不手工复制、不改写、不补数值。所以它们与技能正文始终同源：技能示例改了，这里跟着变。

## 读之前先知道三件事

1. **场景是设定的**。示例里的项目类型、面积、构造参数都来自示例设定，换成你的项目要重新算、重新问。
2. **输出带分级**。数值会标来源档位（S1 国标条文 / S2 检测统计 / S3 经验常数 / S4 行业估算），标准引用会标核验状态（已核验条文 / 标准现行但条文未核验 / 已废止 / 未收录）。没有档位的数，不要用。
3. **隔声不给预测数**。合集现阶段的隔声定量预测处于暂停（PL-229），示例中该维度会标 🔲 并说明「无经验证定量预测」，只给诊断、风险与匹配报告引用。看到 `Rw+C≈` 这类历史演示值时，按行内标注读——那是旧口径，不可作为工程结论。

## 这些文件不是什么

- 不是项目交付文件：不替代设计文件、检测报告与验收结论。
- 不是模板复制粘贴就完事：正式清单、报告须按项目实际参数与设计文件生成。
- 不是性能承诺：产品性能以厂家 CMA/CNAS 检测报告为准，标准以官方现行版本为准。
