# tools/

两个脚本，只用 Python 标准库，不需要装依赖、不联网。

| 命令 | 作用 |
|---|---|
| `python tools/install.py` | 把 15 个技能＋`shared/`＋标准索引装到 `~/.qoder/skills`（可用 `--target` 改目录、`--dry-run` 只看计划） |
| `python tools/smoke_test.py` | 自检：SKILL.md、frontmatter、`../shared/` 引用、8 份治理文件、标准索引 |

装完再跑一次 `smoke_test.py --target <安装目录>`，逐字节核对包内全部技能与共享文件，而不只检查文件存在。没有安装清单的手动安装也可以核对；这不证明文件来自可信发布者，请从项目发布渠道取得技能包。

## 更新与恢复

先下载所需发布版本，再从该包运行下列命令（`<安装目录>` 替换为实际路径）：

```sh
python tools/install.py --target <安装目录> --dry-run
python tools/install.py --target <安装目录>
python tools/smoke_test.py --target <安装目录>
```

- 首次安装生成受管文件清单和内容指纹；以后只更新本包文件，只移除旧清单登记且新版已移除的文件。用户额外文件与其他技能保留，不猜测旧版未登记文件的归属。
- 旧版没有清单、或文件被自行修改/删除时，遇到冲突整批拒绝写入。核对预览后，可加 `--force` 明示备份并替换；不会把跳过旧文件报成更新成功。
- 每次变更前将修改前内容存入安装目录旁的 `<安装目录名>.prefab-interior-backups/update-*.json`，也可用 `--backup-dir <备份目录>` 指定位置。备份含原文，应按原资料保密，不能提交到公开仓或上传；目录须位于技能源及技能安装目录之外，避免宿主扫描备份。
- 常规写入失败自动恢复已经改写的文件；进程被强制结束或断电时不保证自动恢复，可使用本次输出的备份路径恢复。安装和恢复期间应暂停宿主使用技能，成功后重启宿主；文件逐个原子替换，不承诺全包对正在读取的宿主瞬时切换。
- 备份校验和用于发现损坏，不是数字签名；仅恢复自己信任的本机备份。恢复检查目标目录与安装后的文件内容，遇到更新之后的新修改会拒绝覆盖，不提供强制恢复。

```sh
python tools/install.py --restore <备份JSON路径> --target <原安装目录> --dry-run
python tools/install.py --restore <备份JSON路径> --target <原安装目录>
```

恢复前的内容也会备份，可逆向恢复。恢复旧版后，用新版包自检会报告版本内容不一致，这是预期结果；应使用对应旧版包核对。备份不自动过期删除，确认不再需要恢复后由使用者清理。符号链接、Windows目录联接和文件/目录类型冲突会被拒绝，不跟随链接覆盖外部位置。

要求：Python 3.10+。
